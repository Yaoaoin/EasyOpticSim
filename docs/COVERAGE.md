# 0.9：视场、传感器与分析覆盖

## 使用

新建项目默认启用“按传感器自动反求测试视场”。旧项目保留原来的角度配置，主界面会直接提示覆盖缺口，不会偷偷扩大旧处方的优化视场。在“设计目标 → 视场与传感器”可切换：

- 物方角度：保持明确的物方测试方向。
- 跟随传感器：中心、短边中点、长边中点、画面角落。
- 目标像高：输入带符号的毫米列表，例如 `0, 12, 18, 21.63330765`。

像高指当前平面传感器上、项目光谱中最接近 d 线的参考波长主光线交点。`atan(h/EFL)` 仅为理想建议；实际角度沿连接轴上主光线的分支逐步反求。改变镜头、物距、传感器或像面后重新求解。无法求解的目标会明确报错，不能用理想角度替代。

35 mm、36×24 mm 的理想建议为 18.9246°、27.2161°、31.7200°。附带的原创单透镜有明显畸变，其实际角落角度为 **34.0633°**。这是覆盖与数值算法的教学算例，f/35、单色、像差未校正，不能当作成像质量良好的摄影镜头。

## 覆盖报告

主界面、设计目标、衍射、成像预览、扫描与版本报告包含传感器半对角线、实际主光线像高、共同像面 z、采样、遮挡和求解失败。角落必须有匹配的实际测试点（像高容差 0.002 mm），不能因为测试了邻近或更大的像高便自动判为通过。

“声明采样通过”只表示该检查点的配置波长与瞳采样没有失败，不表示像差达标，也不证明整个像圈连续通光。几何采样比例不是精确相对照度。MTF 单独标为未计算、超出模型、未通过或已收敛。旧的保存扫描没有覆盖元数据时显示尚未验证，重新扫描后才生成新的覆盖信息。

## 宽视场与两种衍射方法

几何输入边界扩展至 ±0.7 rad（约 40.107°）。公开验证包括原创 35 mm 单透镜的 ±40°、32°、传感器像高反求和独立主光线瞄准。它是已测算例与求解器边界，不是所有镜头在此角度均能可靠成像的保证。瞄准延拓、求交、全反射、口径遮挡仍分别检查。

快速模型保持原来 ±0.15 rad（约 8.59°）、参考球方向正弦 0.25 的限制，计算结果不因扩大几何范围而自动放行。

新增“直接 Kirchhoff”模型：沿实际光线把光阑映射到参考球，包含全部有效口径遮挡、球面积雅可比、光线管振幅传输和倾斜因子；在最终 **z 为常数的平面传感器** 上直接积分球面距离，不使用小视场傅里叶距离展开。限制仍包括可逆且稳定的瞳映射、空气像方、正参考球距离、参考球横向方向正弦不超过 0.85，以及像面相位梯度的 Nyquist 检查。

对于均匀入射波，球面振幅满足 `A² (d·n) dA_sphere = cos(theta) dA_launch`，面积映射由实际瞳面逆映射 Jacobian 得出。有限物距使用均匀点源及距离平方衰减。未计入界面 Fresnel 损失、镀膜、偏振或真实传感器响应。各波长按用户指定权重分别归一化后非相干相加；不能据此推导绝对照度。

直接法使用 256×256 的有限像面窗口，瞳采样 64→128→256。判据沿用 MTF 最大变化 ≤0.015、PSF L1 ≤0.04、OPD 相邻相位步长 ≤0.25 波长、外侧 10% 窗口能量 ≤0.005；像面 Nyquist 比例须小于 1。它比快速法慢，支持取消。能量在计算窗口内归一化；边缘能量只是窗口指标，**不是全部缺失能量的严格误差界**。很宽的散焦斑、色差或复杂瞳映射可能被拒绝；不能把拒绝改成零像差。

直接法的主要理论依据包括 [标量 Kirchhoff 与 RS 积分的原始比较](https://opg.optica.org/josa/abstract.cfm?uri=josa-63-8-1003)、[焦区传播与球面边界综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC10607893/)。快速法的既有约定保留在 [DIFFRACTION.md](DIFFRACTION.md)。

## 比较与优化

版本对比必须统一视场定义、光谱、物距与传感器。新增显式对焦条件：共用 A 的绝对平面像面，或 A/B 分别自动对焦。共同像面位于 B 最后一面前方时直接报错，不偷偷换像面。实际处方、像面、波长、模型、采样和覆盖信息写入导出报告；按像高比较时，各镜头的实际物方角度可能不同，报告保留这些差异。

优化可设置每个视场 RMS 上限、相对原设计的最大退化、最差视场 RMS、绝对畸变、横向质心色差和最低几何采样通过比例。有限物距尚无此处使用的无限远畸变基准，启用该约束会明确无法通过。只有显式允许遮挡损失时，物理遮挡可以参与受限优化；瞄准、未命中、全反射、材料或求交失败始终禁止通过。实体与空气间隙仍使用连续区间检查。

可按 50%→75%→100% 扩大角度或目标像高，每阶段都与相同条件下的原设计比较；某阶段失败就停止，不能采纳为全视场完成结果。可选择每阶段分别重新对焦。重新对焦后重新生成最终处方的全部约束与边界检查，报告保留实际像面和各阶段取舍。局部优化不保证全局最优。
