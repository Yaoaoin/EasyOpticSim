## 发布与限制

Windows NSIS 包包含 WebView2 离线安装组件、35 mm 与 400 mm 新工作区。发布哈希、资源一致性及启动检查见 [release-0.9.json](release-0.9.json)。未签名；没有在缺少 WebView2 的全新 Windows 虚拟机上执行完整离线安装。

最终安装包 219,479,624 字节（209.31 MiB），SHA-256：`3F8222E6E6013EBDBEDE56AFF03F35A052705D786269E3D86E344FC9978AFDFB`。发布程序启动 5 秒后仍运行且响应，标题正常、产品版本 0.9.0；四份捆绑示例均与源文件哈希一致。用户原始 400mm 文件的哈希保持不变。

直接法采用有限像面窗口并在窗口内归一化，边缘能量不是全部遗漏能量的严格上界。大散焦、强色差、高 NA 或复杂瞳拓扑可能被拒绝。本版不支持矢量衍射、Fresnel/镀膜干涉、精确相对照度、整幅空间变化图像卷积或三维景深。几何采样通过不代表像差或制造条件达标。远程 CI 已补充步骤；本次验收在本机完成，未声称远程工作流已运行。
