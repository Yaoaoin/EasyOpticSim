## 机械与错误情况

- 平面环带在有效口径处接续为恒定 sag，绘图包含精确边界点；有效口径不扩大。
- 调小有效口径会改变遮挡与光学分析，不能通过修改机械外径偷偷扩大通光区域。
- 机械半径小于有效半口径、曲面延伸越界、光学或机械曲面相交均有诊断。
- 同一显式机械镜片要求前后机械外径一致；共享胶合面只有一份参数。
- 覆盖隔着小光阑的两片镜片碰撞：逐对有效口径采样无法看到的外缘碰撞也会报错。
- 覆盖 257 个固定径向采样点全部为正，但采样间存在负间隔的高阶非球面。区间分离检查不会将该模型判为通过。
- 空白文档允许保存，光学计算入口明确拒绝，无空数组崩溃。

## 实际界面流程

通过本地开发界面操作真实 Rust CLI：

1. 从未保存的恢复副本点击“新建项目”，显示保存/不保存/取消选择；“保存后继续”生成真实项目下载。
2. 创建空白项目，显示零表面、搭建指引和禁用的对焦按钮，无错误计算。
3. 添加整枚弯月镜片，设置机械直径 26 mm、前后有效直径 16/12 mm、曲率 0.08/0.05 mm⁻¹，形成平面环带折角。
4. 保存文件，切换到另一个空白项目，再通过文件选择重新打开保存文件；尺寸、材料、设置和计算值一致（有效焦距 52.62 mm、共同边缘厚度 3.0259 mm）。
5. 将机械外径改为 8 mm，系统指出第 2、3 面尺寸错误，并停止光学结果展示；点击诊断可以定位，撤销恢复 26 mm 与正常结果。
6. 新版半径输入显示同一处方的 12.5/20 mm，专业模式仍使用曲率；刷新后恢复最近处方。
7. 机械外径改为 28 mm 后，几何光学指标保持一致；在未保存提示中按 Ctrl+Z 不会修改底层设计，取消提示后仍为 28 mm，关闭提示再撤销恢复 26 mm。

## 发布范围与尚待验收

- 0.3 支持圆柱机械外缘、平面环带和原曲面延伸。倒角、侧壁台阶、边缘透射/反射/散射及非顺序追迹未实现。
- 几何检查用于分离/相交判断；“采样最薄处”不是精确连续极小值，也不是制造强度或公差验收。
- v1 项目可读；新建/机械参数使用 v2。旧版软件不能读取 v2。完整约定见 [MECHANICS.md](MECHANICS.md)。
- 自动恢复副本与用户文件分开；最近文件列表、跨重启保存路径记忆、持久化设计版本不在本次实现范围。
- 文件读写底层经过 Windows 测试，界面保存/选择/重开通过浏览器实际文件验证；桌面原生文件对话框的取消、覆盖以及窗口关闭保护仍需人工完整走查，未将浏览器流程当作原生流程验证。
- 安装包包含离线 WebView2；干净无 WebView2 Windows 环境的断网安装、签名分发与远程 CI 尚未验收。本机编译/启动成功不替代这些检查。
