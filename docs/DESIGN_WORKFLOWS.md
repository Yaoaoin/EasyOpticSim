# 0.8 光圈、设计目标、瞳面与编组工作流

日期：2026-10-19。可从“示例与学习”打开 [400 mm 工作区](../examples/400mm-workflow-0.8.oos.json)，其中已保存五档固定像面扫描、设计目标和一个中前组。它沿用 0.7 的 400 mm f/16 光学处方；原始用户文件与 0.7 修正版均未覆盖。

## 光圈扫描

在“光圈扫描”输入以逗号或空格分隔的 F 数，最多 12 档、范围 0.5–128。界面使用 d 线近轴入瞳，把指定 F 数换算为实体光阑半径；该结果是近轴规格，不证明实体口径全部可用。扫描仅调整光阑有效半径；若独立光阑的机械边界较小，会同步扩大其非成像边界，其他镜片不随之扩口径。

- 固定像面：所有档位使用源处方的同一个像距，适合观察缩光圈的直接影响。
- 每档重新对焦：每档从同一源处方出发，独立调用全视场 RMS 自动对焦，不沿用前一档的焦点。使用现有有界局部搜索，不能保证找到任意系统的全部焦点。
- 几何采样：选择 9、17、25 或 33；每档保存视场 RMS、失败/总样本数、瞄准失败数、物理遮挡数及最终像距。
- 可选多色 MTF：逐视场执行现有采样收敛与适用性检查，记录弧矢/子午在 10、30 lp/mm 的数值和收敛指标。失败记录保留具体原因，超出频率网格显示未定义。MTF 使用实际被裁剪后的瞳，单位能量归一化，不是相对照度或总透射率。

最佳档只按无失败样本的全视场均方 RMS 选择。它不是综合衍射画质的最优光圈；例如缩光圈可降低几何光斑，却降低某些频率的衍射 MTF。失败档的 RMS 只来自有效光线，不参与最佳档选择，也不会以零误差代替失败。

“复核并生成所选光圈候选”重新执行全部视场/波长的 33×33 追迹，并检查项目已启用的设计与几何约束。全部通过才可采纳。扫描本身不修改当前光学处方。取消保留上一次完整记录，不保存部分结果。

候选同时绑定当前文档、名称、光学处方、目标和优化边界。修改这些输入、撤销/重做改变这些输入或打开文件时，旧候选任务同步失效；迟到结果不得回填。扫描源名称可以保留原始记录，采用候选时沿用当前项目名称和描述。

设置、源处方和完整摘要随项目 JSON/CSV 保存；不保存大型 PSF 数组。恢复记录时，按排序后的光学字段比较源处方，避免 Rust/JSON 属性顺序造成误判。处方改变后，旧扫描仍可查看和导出，但禁止直接生成候选。编组名称、优化设置等工作区信息不会使扫描过期。

## 设计目标

“设计目标”并排显示目标、当前值与差距。焦距、最大总长、中心/实体厚度和空气间隔沿用已有约束；可额外启用：

- 近轴 F 数及绝对容差；
- 最小无限远近轴后焦距；
- 最大第一镜片有效直径。

目标 F 数是优化目标，不能当作实际光阑半径。400 mm f/2.8 需要约 142.86 mm 的入瞳；当前 70 mm 前口径会显示明确的无限远轴上尺寸限制。尺寸需求通过也不代表通光、像差或制造要求通过。有限物距显示无限远规格估计提示，尚未计算摄影工作 F 数。

可直接设置传感器尺寸，并显式按目标焦距生成中心、0.7 和最大对角半视场；只用于无限远近轴初值。不会自动通过画面缩放实现目标焦距。当前设计的检查表附带预览采样的失败光线项；优化候选仍使用 33×33 复核。

“将光阑半径加入优化变量”增加仅限光阑面的 `aperture` 变量，可在专业模式设置上下限和锁定。新增目标进入局部阻尼最小二乘的残差与最终采纳检查；几何失败或任何采样失败仍被拒绝，不为实现较大光圈而放宽通光约束。材料不自动更换，前组也不自动扩径。

## 可交互瞳面图

选择视场、波长与奇数采样 7–33（UI 提供 9/13/17/25/33），在实体光阑平面规则圆盘中逐点瞄准和真实追迹：

- 绿色：到达像面；
- 红色：物理追迹终止，可查看实际终止面和原因；
- 黄色：瞄准未解，目标光阑与试算诊断单独展示，没有可绘制的物理路径。

点击点或使用方向键选择，剖面用白线高亮所选真实光路，并联动表面选择。剖面是 Y/Z 投影，X 坐标在瞳面图查看。计数不是照度、矢量电磁场或波前图；稳定主光线分支求解仍不穷举任意折叠瞳。瞳面路径临时计算，不作为持久化结果塞入项目文件。

## 多镜片编组与移动

选择至少两枚相邻完整镜片创建命名组，范围内所有镜片、间隔和光阑一起归组，不拆开胶合面。最多 20 个非重叠连续组。移动只改变组前和组后的空气间隔；组内所有表面的曲率、材料和内部间隔保持不变，组外镜片和传感器轴向位置固定。

先检查移动候选，连续几何分离或边界间隔不合格就拒绝。应用后再重新计算光学性能，支持撤销/重做。几何通过不表示新镜头的通光或画质达标。

第一面固定为坐标原点，包含首面的组可以保存和定位，但不能整体平移；当前版本不引入首面全局坐标偏移。新增、复制、删除表面会清空编组，避免面号引用错位。命名版本保存当时的编组定义，恢复旧版本时同时恢复该定义。设计目标与扫描记录属于项目工作区；恢复不同处方后，相应扫描会显示过期。

## 接口与验证

新增 CLI 操作 `aperture_scan`、`stop_map`、`move_group` 和 `checks`；均使用同一 Rust 核心。`aperture_scan` 返回源处方、配置、逐档摘要与最佳几何 RMS 索引；`stop_map` 返回逐点目标与含阶段的 RayPath；`move_group` 返回几何有效的候选处方；`checks` 返回规格与几何检查，不单独进行通光认证。当前 UI 附加已完成的预览通光检查，候选另做精细复核。

重现：

```powershell
cargo test --workspace --release --locked
cargo build -p oos-cli --release --locked
pnpm test
python scripts/validate_design.py
python scripts/validate_diffraction.py --extra-project examples/400mm-repaired.oos.json --output docs/validation-diffraction-0.8.json
```
