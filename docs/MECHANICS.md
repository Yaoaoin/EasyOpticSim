# 0.3 镜片与机械边缘

## 从零搭建

1. “新建项目”（Ctrl+N）选择空白或教学模板，填写项目名、传感器、物距和视场。
2. 左侧选择双凸、平凸、双凹、弯月或胶合双片，点击“添加镜片”。空白项目自动加入独立光阑和到像面的间隔。
3. 基础模式选择整枚镜片/胶合组，编辑每片材料、中心厚度、各面曲率与有效直径、整个组的机械外径、镜后间隔。胶合面是共享的单一表面。
4. 前后面分别选择“平面环带 / 方边”或“继续曲面”。有效直径小于机械外径时，环带在剖面上形成明确折角。内置“机械环带探索”可直接观察。
5. 查看“几何检查”，点击诊断定位表面；随后对焦、分析。添加到现有设计时，原像面距离成为新镜片之前的空气间隔，请按设计意图调整。
6. 保存（Ctrl+S）和另存为（Ctrl+Shift+S）；打开（Ctrl+O）恢复处方、材料、机械边缘和分析设置。新建/切换/关闭桌面窗口前有未保存保护。

复制、删除作用于整个胶合组，不会拆开共享界面。删除合并两侧空气间隔，镜片自身厚度随之移除。各操作支持撤销/重做。专业模式仍可逐面编辑，因而也可以暂时产生不完整或非法处方；错误草稿允许保存重开，分析需先通过校验。

## 数据与追迹约定

- v1 项目保持可读；使用机械边缘后存为 `schema_version: 2`。老版本软件不能读取 v2。
- 每个表面可有 `mechanical: { semi_diameter, shape }`，长度 mm，shape 为 `flat` / `curved`。没有该字段时，外形终止于原有效半口径。
- flat：在有效口径之外保持边缘 sag 常数，形成平面环带；curved：将原 sag 延伸到机械半径。
- 当前显式机械镜片为同轴圆柱外缘，同片前后机械外径必须相同。非圆柱侧壁、台阶侧壁和倒角不在 0.3 内。
- `semi_aperture` 始终是光学有效半口径。机械延伸是非成像区域，既不添加折射界面，也不扩大有效口径；超出有效口径的光线仍报告遮挡。未追迹边缘透射、反射或散射。
- 未引入额外的镜片处方副本：界面根据连续玻璃区间推导单片/胶合组，所有修改直接作用于原表面模型。
- CSV v2 在原十列后增加 `mechanical_semi_diameter,edge_shape`；两列均空表示没有显式边缘。项目元数据和材料快照保持在 `#oos=` 首行。

## 几何检查范围

检查相邻表面及有独立光阑隔开的相邻镜片，在共同径向范围内的轴向分离。新机械模型采用相同外径，因此完整镜片厚度域被覆盖。旧项目未指定机械尺寸时，检查与绘图不能代替完整机械设计。

平面环带边界作为分段点。每段用曲面导数的保守区间界限验证最小分离；仅采样通过不能使检查通过。负间隔超过 `1e-9 mm` 被拒绝，病态数值或预算内不能确认分离时也报告诊断。表格的“采样最薄处”是采样估计，并非连续全局极小值的精确测量。当前没有用户可配置的制造最小厚度约束、镜筒、倒角、公差或应力分析。

完整光学计算继续使用原旋转对称顺序追迹、参考球面 PSF/MTF 和局部平面成像。纯机械外径编辑的数值不变性见 [回归报告](validation-mechanics.json)，既有衍射范围见 [DIFFRACTION.md](DIFFRACTION.md)。

## 保存与恢复

桌面原子保存先写目标目录临时文件、同步，再替换目标。成功后才更新保存状态；取消对话框或写入失败不会清除未保存标记。保存使用当前已选路径，另存为重新选择；CSV 导出不会替代原生项目保存状态。

自动恢复在本机保存最近编辑的处方。恢复后视为未保存副本，需要明确选择文件保存。0.3 暂不提供最近文件列表或跨重启记忆原保存路径，也不把自动恢复视为已经保存到用户文件。浏览器开发界面使用下载/上传；安装版使用原生文件对话框。
