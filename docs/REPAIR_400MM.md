# 0.7 瞳瞄准、失败光路与 400 mm 修复

日期：2026-10-19。原始用户文件保持不变；其 SHA-256 为 `84627e7a4c374417169e2c1fcaf6fd88a951c7ab4ed5ef034a32e01b5e67b561`。

## 软件修复

原处方在 d 线上的前组到光阑映射存在折叠：同一个光阑坐标可能有多个发射位置，某些目标在有限前口径中不可达。旧求解器失败时把忽略口径的 Newton 试算路径交给画布，造成实际超过 S1 口径的光线仍被画到后续表面。这些红线不能解释为真实物理追迹。

新瞄准器为每个视场/波长缓存主光线，以近轴矩阵初始化，使用限步、回溯和二维有限差分 Jacobian；直接求解不成功时沿主光线分八步延拓。相对于主光线的 Jacobian 翻转会被拒绝。瞄准成功后重新执行带完整口径的物理追迹；失败返回 `aiming_failed` 和空路径，保留目标、残差、迭代数及试算诊断。

这一策略改善稳定分支上的求解，不穷举任意多根或断裂瞳。未找到稳定解会明确显示为“光阑瞄准”，不冒充已经确认的口径遮挡。物理阶段分别报告遮挡、未命中、全反射与求交不收敛；逐视场/波长的计数和失败总数一致。“定位”在瞄准失败时指目标光阑，在物理失败时指实际终止面。画布可单独隐藏物理失败路径。

近轴 F 数是计算的瞳共轭估计；存在失败光线时提示“通光尚未确认”。有效光线的 RMS 不能掩盖失败样本，优化仍拒绝任何失败采样。无限远负后焦距直接说明焦点在最后一面前方，后方像面自动对焦不能修复这种结构。

## 处方修正

[修正版](../examples/400mm-repaired.oos.json)保存了“用户原始处方”和“400 mm f/16 实像修正版”两个命名版本。原始文件未覆盖。通过“示例与学习”可直接打开，或使用“打开”加载该 JSON。

原处方实际焦距为 50.3796 mm、后焦距为 −42.8819 mm，不能由移动后方传感器变成 400 mm 成像镜头。修正版保留 34 个表面的顺序、Teaching crown/flint 材料快照及所有内部轴向间隔，重新分配曲率，扩大部分后组有效/机械半径，并调整光阑和像距。未自动换成未经确认的商品镜头材料。

| 指标 | 修正版 |
|---|---:|
| 有效焦距 | 399.997640 mm |
| 近轴 F 数 | 15.999906 |
| 近轴后焦距 | 389.338207 mm |
| 最后一面到平面传感器 | 388.786311 mm |
| 第一顶点到传感器总长 | 552.686311 mm |
| 入瞳直径 | 25 mm |
| 半视场 | 0°、2.167009°、3.095727° |
| 多色 RMS，65×65 | 9.231、7.555、14.105 µm |
| 几何分离采样最小值 | 0.049303 mm |

三视场使用 F/d/C 等权重，最大视场按全画幅对角线设置。65×65 网格共 28,881 条光线、七径向视场共 67,389 条光线，均无失败。几何连续分离检查通过；最薄处数值仍是采样估计，不是加工公差或装配强度认证。

三个视场的多色 PSF/MTF 均通过 64→128 瞳采样收敛门槛；最大 MTF 变化小于 0.00119，PSF L1 小于 0.0222，边带能量小于 0.229%。测试图生成三个有效局部视场画面。RayOptics 独立重追、参考球 OPD 和 NumPy FFT/复杂 OTF 对照见 [波动报告](validation-diffraction-0.7.json)。

修正采用独立数值工具辅助局部优化，并以 OSS 完整几何、波动和约束检查验收；不承诺全局最优。内置约束优化只移动像面时，57 项检查全部通过，候选可采纳；原修正版没有被该验证候选覆盖。

这是一份能形成后方实像的 400 mm f/16 教学处方，使用合成教学玻璃，总长较大。它不代表佳能原设计，也未达到 f/2.8。400 mm f/2.8 的入瞳需约 142.86 mm，而原前组有效直径只有 70 mm；要实现该目标，需要扩口径、重设计前后组并引入合适材料，不能只修改光阑。

## 重现

```powershell
cargo test --workspace --locked
cargo build -p easyopticsim-cli --release --locked
pnpm test
python scripts/validate_aiming.py
python scripts/validate_diffraction.py --extra-project examples/400mm-repaired.oos.json --output docs/validation-diffraction-0.7.json
```

Python 仅用于开发验证。生产运行不需要 Python、RayOptics 或数值优化脚本。完整测试与发布边界见 [测试报告](TEST_REPORT.md)。
