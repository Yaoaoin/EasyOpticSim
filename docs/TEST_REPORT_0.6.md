## 独立光学对照（本版本重新执行）

- RayOptics 0.9.10，6 个模型、378 条显示光线；最大交点误差 `9.9741e-11 mm`。覆盖球面、非球面、有限物距与机械元数据模型。验证交点、方向与光程，不把这一项当作瞳瞄准或衍射认证。
- RayOptics 几何路径、参考球面 OPD 与 NumPy FFT/复杂 OTF：5 个衍射算例，最大 OPD 差 `6.5984e-11 mm`，MTF 最大绝对差 `2.8259e-8`。包含多色、离轴、有限物距、非球面与遮挡情况。
- 65,536 个局部目标成像像素，8 位输出最大差为 0；平均能量误差 `3.0e-15`。

原始记录：[几何](validation-rayoptics.json)、[波动与成像](validation-diffraction.json)。限定标量、规则投影瞳模型，仍须现有适用性和采样收敛门槛；不声称任意镜头的普遍精度。

## 实际界面验收

使用开发浏览器界面与真实 Rust 0.6 CLI，27 面、12 组压力处方：

- 48 项约束中 16 项失败，汇总和默认过滤表均展示全部 16 项；切换全部显示恢复 48 项且失败优先。标题、实际值、余量与结果列一致。
- 仅留不可达焦距时，47/48 项通过，明确写出“焦距绝对误差”阻止采纳；目标恢复可达值后 48/48 项通过，采纳按钮启用并可应用。
- 观察到实际第 4/25 次进度、目标值与 RMS；取消后没有过期候选回填。
- 完整优化报告导出包含 48 条检查、16 条轨迹记录与候选处方。
- 变量表可跨 S2、S4、S27 设置；超界值阻止应用，恢复合法边界后可保存两行锁定、一行参与与 30 次上限。
- 名称 BK7、nd 1.5–1.6、Vd 60–70 联合过滤得到 1 条；仅替换 S2–S3 为 N-BK7。
- 真实 UI 保存文件并重新打开，3 行变量、边界、锁定、边缘优先预设、版本预设、原始材料与 N-BK7 系数完整保留。
