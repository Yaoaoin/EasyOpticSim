## 版本定位

Y1.2 将 Ayr1k 贡献的引导式 EOS 设计工作流和独立复核助手纳入正式 EasyOpticSim 发行版。新手默认只需要理解目标、当前画面和最终检查；所有自动改进仍使用候选机制，并经过几何、约束、覆盖、遮挡与衍射复核。

EasyOpticSim 继续依据 Apache License 2.0 分发。根目录 `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.txt`、字体 OFL 和玻璃目录 CC0 声明继续随源码和安装包分发。

## 三入口引导工作区

- 「我的目标」：设置目标焦距、F 数和长度等条件，同时显示当前实际计算值。
- 「画面与改进」：查看各画面位置的几何光点 RMS，选择全画面、中心或边缘优先，再让助手尝试改进。
- 「检查与保存」：运行完整体检，处理失败项，保存项目或导出图纸。
- 结构编辑、精细画质、测试图、手动扫描、版本和图纸保留在「更多工具」；高级工作区继续提供全部专业功能。

## 六步新建向导

新建项目依次完成：

1. 选择人像、风景、远处细节或近物用途。
2. 选择画幅和拍摄距离。
3. 设定目标焦距、F 数和项目名称。
4. 查看模板来源、已知限制与目标差距。
5. 运行 33×33 基础结构、几何、覆盖和约束检查。
6. 创建可继续验证的起点；跳过检查或未达标时明确标为实验草稿。

四类模板使用稳定 ID 与明确示例文件绑定，保留真实材料、波谱和结构限制，不再依赖库顺序或名称匹配。教学模板仍是计算起点，不是自动达标的成品镜头。

## 独立复核设计助手

- 先检查原始镜头结构、光线追迹和画幅覆盖；存在阻断问题时不进入优化。
- 默认最多尝试五个非光阑曲面曲率与最后像距，遵守现有变量表、锁定和上下界。
- 不自动改变材料、画幅、波长、口径或设计目标，也不会为了得到结果放宽约束。
- 原设计与候选均使用 65×65 几何采样；逐视场不允许退步，遮挡不得增加。
- 重新检查结构连续性、设计约束、画质底线和传感器中心/边缘/角落覆盖。
- 候选所有画面位置执行最高 128 瞳采样的衍射检查，并要求引擎报告收敛。
- 结果显示逐视场 RMS、焦距、F 数与参数变化；只有用户进入候选卡片确认后才会修改处方，且支持撤销。
- 找不到可验证改进时明确停止，原设计保持不变。

## 体检与稳定性改进

- 一键体检的 PSF/MTF 检查由中心和边缘扩展到全部分析画面位置。
- 正式加入当前设计目标约束检查，目标未满足不会写成通过。
- 项目变化、取消计算或离开页面时会终止旧任务并清空旧结果，避免过期数据回填。
- 首次引导、工作区帮助和 22 章离线手册更新为 Y1.2 流程。

## 兼容性

## 已知限制

- 助手的改善指标是几何光点 RMS，不保证全部空间频率的 MTF 同时改善。
- 有限采样、衍射收敛和一键体检不代表制造公差、镀膜、杂散光、机械强度、装配或真实相机系统认证。
- Y1.2 不提供全局镜头结构搜索、自动选玻璃或自动生成镜头结构。
- 安装包未签名；干净 Windows 的断网安装、升级和卸载仍需额外验收。
