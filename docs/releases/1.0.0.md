# OpenOpticSim 1.0.0

面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0；自研 Rust 双精度顺序追迹核心。

构建与本地验证日期：2026-10-19。实际发布日期以 GitHub Release 为准。

[下载 Windows 安装包](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.0.0/OpenOpticSim_1.0.0_x64-setup.exe) · [SHA-256 校验清单](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.0.0/SHA256SUMS.txt) · [源码仓库](https://github.com/ayr1k/OpenOpticSim)

## 用户可以完成什么

打开示例 → 编辑整枚镜片、材料、机械边缘与镜组 → 检查通光和传感器覆盖 → 对焦、扫描与分析画质 → 在统一条件下比较版本 → 检查并采纳优化候选 → 保存项目与导出 PDF 名义技术图纸。

1.0 将全部既有工具整理为设计、画质、调校、交付四组，增加可检索离线手册、上下文帮助、功能搜索和完整参数图纸。自研光学引擎与 0.9 计算范围保持一致，旧项目继续读取。完整条目见 [更新日志](https://github.com/ayr1k/OpenOpticSim/blob/v1.0.0/CHANGELOG.md)。

- 镜片与表面编辑、机械环带、几何检查、镜组编组 / 移动与画布缩放平移。
- 点列图、像差、PSF / MTF、局部平面成像、交互瞳面与失败光线诊断。
- 传感器联动、目标像高、覆盖缺口、对焦 / 光圈扫描和带约束局部优化。
- 持久化版本、统一条件 / 尺度对比、JSON / CSV 往返、PDF 名义技术图纸与完整参数附件。
- 20 章离线手册、F1 上下文帮助、Ctrl+K 功能搜索；不要求账户。

## 安装与开始

- 平台：Windows x64；Windows 10 / 11 是目标环境，具体最低系统兼容尚未完成独立矩阵验收。
- 下载资产：`OpenOpticSim_1.0.0_x64-setup.exe` 与同一 Release 的 `.sha256`。源码 ZIP 面向开发者，运行软件请选择 `.exe` 安装包。
- 安装包包含 WebView2 离线安装组件、手册、字体和许可；应用运行不需要 Node、Python、Rust 或本机开发服务器。
- 安装包未签名。干净、无 WebView2 的 Windows 断网安装尚待实际验收，不将“构建成功”描述为该测试已通过。
- 项目文件保留在用户选择的位置。升级前建议备份自己的 `.oos.json`；不要将未保存的内存状态作为唯一副本。

下载后校验：

```powershell
Get-FileHash .\OpenOpticSim_1.0.0_x64-setup.exe -Algorithm SHA256
Get-Content .\OpenOpticSim_1.0.0_x64-setup.exe.sha256
```

正式下载附件的哈希以该 Release 的 `SHA256SUMS.txt` 和 `manifest.json` 为准。校验值用于检查文件一致性，不替代发布者签名。源码内较早的本地准备记录仅作为历史证据，不作为新下载文件的校验依据。

打开软件后按 F1 查看帮助，Ctrl+K 搜索功能；推荐从“单透镜”或“双胶合探索”开始，再阅读 [新手教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.0.0/docs/manual/start.md)。

## 适用范围与已知限制

- 可见光、旋转对称、顺序折射、有限 / 无限物距、平面传感器；具体范围以 [STATUS](https://github.com/ayr1k/OpenOpticSim/blob/v1.0.0/docs/STATUS.md) 和 [COVERAGE](https://github.com/ayr1k/OpenOpticSim/blob/v1.0.0/docs/COVERAGE.md) 为准。
- PSF / MTF 使用限定范围的标量模型，需关注收敛与适用性；瞳求解失败不等于物理遮挡。
- 成像预览为局部平面目标，不是完整三维摄影场景或整幅空间变化渲染。
- PDF 图纸是名义设计记录，未指定的公差、表面质量、镀膜和装配要求不会自动生成。
- 400 mm 示例为用户自建模型的教学修正，约 f/16，不是佳能官方处方或 400 mm f/2.8 复刻。
- 原生文件对话框 / 快捷键的完整人工验收，以及干净 Windows 离线安装仍待补齐。
- 本地验证不替代远程 CI 或全新 Windows 环境验证；线上状态由维护者在 [Actions](https://github.com/ayr1k/OpenOpticSim/actions) 确认。
