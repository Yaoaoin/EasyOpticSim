# OpenOpticSim 1.1.0

面向摄影与镜头爱好者的开源、本地光学设计与模拟工作室。Windows x64，Apache-2.0；自研 Rust 双精度顺序追迹核心。

**本版重点：固定传感器的镜组对焦、多配置变焦模拟，以及独立的 24–70 mm 教学示例。** 保留 1.0 的设计、画质、调校与交付功能。

构建与本地验证日期：2026-10-19。实际发布日期以 GitHub Release 为准。

[下载 Windows 安装包](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.1.0/OpenOpticSim_1.1.0_x64-setup.exe) · [SHA-256 校验清单](https://github.com/ayr1k/OpenOpticSim/releases/download/v1.1.0/SHA256SUMS.txt) · [源码仓库](https://github.com/ayr1k/OpenOpticSim)

## 用户可以完成什么

打开镜头 → 建立运动镜组与命名配置 → 固定传感器调整镜组位置 → 检查对焦或求解变焦补偿 → 比较不同配置的画质与覆盖 → 验证中间运动位置 → 保存项目与导出含配置参数的 PDF 名义技术图纸。

完整条目见 [更新日志](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/CHANGELOG.md)。

### 镜组对焦与多配置变焦

- 支持整枚镜头伸缩对焦、内部镜组对焦，以及单个补偿镜组的变焦求解；计算时保持传感器位置固定。
- 一份共享处方保存多个命名配置，分别记录物距、镜组位移、目标焦距与光圈规则。
- 设置镜组行程、锁定和最小空气间隙，检查几何相交、越界、通光及追迹失败，并提供具体诊断。
- 保持参考实体光阑，或依据实际近轴入瞳调整到目标 F 数；口径调整受参考开口限制。
- 支持相邻配置的位置插值与 11 点轨迹检查，显示镜组位置和运动曲线。
- 固定像面对比全部配置，使用共同尺度展示点列图，提供实际焦距、F 数、RMS、覆盖和有限物距倍率等结果。

目标焦距用于比较，单补偿组求解不会自动保证同时达到目标焦距与最佳对焦。候选结果需检查后采纳；编辑配置不会直接替换主画布。

### 独立的 24–70 mm 教学示例

新增“**24–70 mm · 双镜组教学变焦**”，包含 24、35、50、70 mm 四个配置，用于学习镜组移动、补偿、配置比较与中间位置验证。

示例采用自主构建的双镜组结构和合成教学材料，按 Apache-2.0 分发。传感器为 **4×3 mm**，F 数随焦距约从 **f/10 变化至 f/29.17**。它不是商业全画幅 24–70 mm f/2.8 镜头的处方或复刻，也不代表恒定光圈性能。

### 保存、帮助与图纸

- 原生 `.oos.json` 保存共享参考处方、全部运动配置、行程和光圈规则；撤销与命名版本保留相应配置状态。
- 普通处方参数编辑同步到共享参考；改变表面结构时清除不兼容的运动配置，避免错用面号。结构修改前建议保存命名版本。
- 离线手册新增“配置与镜组运动”章节，提供五分钟教程、坐标约定、求解条件和结果解释。
- PDF 名义技术图纸增加当前配置标识及镜组配置参数表，内嵌原生项目保存全部配置。

## 安装与开始

- 平台：Windows x64；Windows 10 / 11 是目标环境，具体最低系统兼容尚未完成独立矩阵验收。
- 下载资产：`OpenOpticSim_1.1.0_x64-setup.exe` 与同一 Release 的 `.sha256`。源码 ZIP 面向开发者，运行软件请选择 `.exe` 安装包。
- 安装包包含 WebView2 离线安装组件、手册、字体和许可；应用运行不需要 Node、Python、Rust 或本机开发服务器。
- 安装包未签名。干净 Windows 环境中的离线完整安装与升级尚待实际验收。
- 升级前建议备份自己的 `.oos.json`。1.0 项目可继续读取；新增运动配置请使用 1.1.0 编辑和保存，不依赖旧版保留新字段。

下载后校验：

```powershell
Get-FileHash .\OpenOpticSim_1.1.0_x64-setup.exe -Algorithm SHA256
Get-Content .\OpenOpticSim_1.1.0_x64-setup.exe.sha256
```

正式下载附件的哈希以该 Release 的 `SHA256SUMS.txt` 和 `manifest.json` 为准。校验值用于检查文件一致性，不替代发布者签名。

体验本版新功能：

1. 在“示例与学习”中打开“24–70 mm · 双镜组教学变焦”。初始画布为 70 mm 参考处方。
2. 进入“调校 → 配置与镜组运动”，选择“24 mm”，点击“检查当前配置”。
3. 查看实际焦距、F 数、RMS、覆盖与候选光路，再点击“采纳到当前配置与画布”。
4. 点击“固定像面对比全部配置”，查看各焦段的同尺度点列图。
5. 展开“手动变焦轨迹与中间位置”，检查插值位置或验证 11 个位置；保存原生项目以保留配置。

按 F1 查看帮助，Ctrl+K 搜索功能。详细操作见 [镜组对焦与变焦教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/docs/manual/motion.md)；初次使用可先阅读 [新手教程](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/docs/manual/start.md)。

## 适用范围与已知限制

- 可见光、旋转对称、顺序折射、有限 / 无限物距、平面传感器；具体范围以 [STATUS](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/docs/STATUS.md) 和 [COVERAGE](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/docs/COVERAGE.md) 为准。
- 本版求解器对一个镜组执行有界行程扫描与局部细化，不承诺全局最优。多组联合对焦、自动生成变焦凸轮曲线和全焦段联合优化尚不支持。
- 轨迹检查验证离散位置，不证明连续齐焦；位置插值也不等于焦距线性变化。几何采样通过不代表全部传感器覆盖或衍射分析通过。
- PSF / MTF 的模型适用范围和收敛要求延续 1.0，未因增加变焦功能而扩大。成像预览仍为局部平面目标，非完整三维摄影场景。
- PDF 图纸是名义设计记录；光学指标对应当前处方，配置参数表不代表全部配置已完成验收。未指定的公差、表面质量、镀膜和装配要求不会自动生成。
- 400 mm 示例仍为用户自建模型的教学修正，约 f/16，不是佳能官方处方或 400 mm f/2.8 复刻。
- 干净 Windows 离线安装、升级，以及原生 PDF 保存对话框的端到端验收尚待补齐。本地验证不替代远程 CI，线上状态请查看 [Actions](https://github.com/ayr1k/OpenOpticSim/actions)。

## 验证与反馈

本轮 **59 项前端测试、81 项 Rust / 桌面测试**、Clippy 检查及生产构建通过。已验证桌面程序启动、打包资源一致性及发布附件 SHA-256，并检查二进制中的个人路径。

- 24 / 35 / 50 / 70 mm 四个关键配置完成独立近轴矩阵与 RayOptics 交点 / 光程对照；三段轨迹共 33 个采样位置通过声明的几何验收。
- 瞳采样由 17 提高至 33 后，示例各焦段 RMS 的最大变化约为 0.032 μm。该结果仅针对已验证算例和采样条件。
- 400 mm 修正版完成固定传感器、10 m 物距的镜组对焦验证；既有保存回归的 38,508 条覆盖采样与基准一致。
- 已检查示例加载、配置检查与采纳、保存重开、四配置比较，以及 PDF 配置参数表和内嵌项目一致性。

详细证据见 [镜组运动验证](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/docs/validation-motion-1.1.json) 与 [1.1 发布验收](https://github.com/ayr1k/OpenOpticSim/blob/v1.1.0/docs/validation-release-1.1.json)。下载文件的构建状态以附件 `manifest.json` / `build-report.json` 为准。
