# OpenOpticSim 1.1.0

本版增加镜组运动与多配置模拟，保留 1.0 的已有功能。

## 新增

- 固定传感器的整组伸缩 / 内部对焦，单补偿组变焦求解。
- 共享处方、命名配置、行程与锁定、最小空气间隙、实体光阑或目标 F 数。
- 变焦位置插值、11 点轨迹检查、固定像面同尺度对比、有限物距倍率与报告。
- 单独的 24–70 mm 教学示例（24/35/50/70 mm），4×3 mm 小传感器和小光圈，非商业全画幅 f/2.8 处方。
- 保存、重开、撤销和命名版本保留运动配置；帮助新增镜组运动教程，技术图纸附配置参数表。

## 验证与边界

关键焦段经独立近轴矩阵和 RayOptics 交点 / 光程对照；17→33 瞳采样收敛检查；400 mm 修正版执行固定传感器的 10 m 对焦。详细数值见 docs/validation-motion-1.1.json。

变焦中间位置均需重新追迹；离散检查不证明连续齐焦。求解器为一维行程扫描及局部细化，不承诺全局最优。外场 PSF/MTF 适用范围与收敛要求延续 1.0，不因变焦功能扩大。

Windows x64 安装包未签名，包含离线 WebView2 安装组件。干净 Windows 虚拟机中的离线完整安装、升级和原生 PDF 保存对话框验收尚未完成。安装包 SHA-256 以同目录 SHA256SUMS.txt 为准。

## 使用

示例与学习 → 24–70 mm · 双镜组教学变焦 → 调校 → 配置与镜组运动。选择配置，检查后采纳；保存原生 .oos.json 保留全部配置。

标签和 GitHub Release 由维护者发布。本地构建附件在 artifacts/release-1.1.0；提交最终源码后重新运行 scripts/stage_release.py，绑定最终提交并更新附件清单。
