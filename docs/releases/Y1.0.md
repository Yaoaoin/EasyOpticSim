## 版本定位

Y1.0 是 OpenOpticSim 的新手体验迭代，基于 Ayr1k 上游 1.1 功能集。它不替换光学引擎，也不改变已有项目格式；主要目标是减少第一次设计镜头时的术语和导航负担，并建立冰川蓝玻璃视觉系统。

本 fork 继续按 Apache License 2.0 分发。根目录 `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.txt`、字体 OFL 和玻璃目录 CC0 声明均原样保留。Y1.0 不声称拥有上游代码或第三方资产的独占版权。

## 新功能

### 三步新建向导

新建项目从表单改为三步任务：

1. 选择人像、风景、远摄或近物用途。
2. 确认自然语言效果、项目名称和可选精确设置。
3. 从可计算教学示例或完全空白项目开始。

用途会生成正式的目标焦距、F 数、允许误差、后焦距、前组口径、物距、传感器和视场设置。预设是设计目标，不会静默改变示例的实际光学处方。

### 简单 / 专业双模式

简单模式默认启用，把原来的十五个工具整理成：

1. 告诉我想拍什么
2. 搭建镜头
3. 让画面更好
4. 检查与保存

每一步只显示当前需要的工具。顶部可随时切换专业模式，恢复设计、画质、调校、交付四组完整工作区。切换不重载项目、不丢失编辑，也不写入项目 schema；偏好仅保存在本机。

### 冰川蓝玻璃主题

- 深冰川蓝渐变背景和分层半透明面板。
- 统一的颜色、描边、焦点和状态设计令牌。
- 主操作使用高对比冰蓝色；成功、警告和错误保持独立色相。
- 光路图使用低干扰深色底，避免玻璃效果降低光线可读性。
- 支持 `prefers-reduced-motion` 与 `prefers-reduced-transparency`。
- 不支持 `backdrop-filter` 时使用实色面板，不影响功能。

### 工程保障

- 新增 `experience.ts`，隔离本机 UI 偏好和光学项目数据。
- 新增体验模式默认值、持久化和简单导航映射测试。
- 保持 `.oos.json`、CSV、v1/v2/v3 schema、Rust 接口和候选采纳机制兼容。
- 用户可见 Y1.0 对应合法 Cargo/Tauri/npm 版本 `1.1.0-y1.0`。

## 升级说明

- 上游 1.0/1.1 项目可以直接打开；建议升级前备份自己的 `.oos.json`。
- 第一次启动默认进入简单模式；熟悉原界面的用户可在顶部切换“专业”。
- 简单模式和专业模式共享同一项目、撤销历史和计算结果。
- Y1.0 保存的光学项目仍使用现有 schema；用途描述和设计约束使用现有合法字段。
- 较旧版本会忽略它不认识的工作区字段；重要项目建议仍用 Y1.0 重开确认。

## 已知限制

- 简单模式是交互层，不是新的自动镜头设计器；实际能力仍取决于处方和计算结果。
- 用途预设只建立目标，不保证所选教学处方已经达到该目标。
- PSF/MTF、机械连续区间、有限物距和大视场分析仍受原项目文档声明的适用范围约束。
- 背景虚化等自然语言只用于解释目标倾向，当前局部平面预览不模拟完整三维景深或真实散景。
- 安装包仍未签名；干净 Windows 的断网安装、升级和卸载验收尚未完成。
