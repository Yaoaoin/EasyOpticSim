# 0.6 优化、材料与采纳检查

## 多表面设计

切换“专业 → 优化 → 编辑多表面变量”。可添加任意表面的曲率、面后间隔和 A4/A6/A8/A10。间隔属于所选面之后的介质，最后一面间隔就是像距。曲率单位 1/mm，A4/A6/A8/A10 单位依次为 mm⁻³/⁻⁵/⁻⁷/⁻⁹。

每行可设上下限或锁定。空白边界表示无限制；锁定行保持原值。最多 100 行配置、12 个同时参与变量、1–100 次迭代。当前值必须在边界内；不允许重复变量。修改表面数量时清空变量引用，避免插入或删除后优化错面。改变处方造成当前值超界时仍可保存草稿，重新优化前修正范围。

变量表、边界、锁定和预设随项目保存，JSON/CSV 均包含。恢复不同面数的版本会清空变量引用；约束继续使用当前工作区设置，需要按新处方确认。

## 画质目标与过程

三种预设以多色 RMS 光斑均方构造目标，全部视场仍参与通光和几何验收。令 t = |视场| / 最大 |视场|，原始权重为：中心优先 1+3(1−t)²；均衡 1；边缘优先 1+3t²，再归一化为总和 1。全部视场为零时采用相同规则，结果等权。预设不改变 PSF/MTF 或几何分析本身，也不改变仪表上的等权多色 RMS 定义。

实时进度来自每次实际迭代，展示加权 RMS、归一化目标值、焦距与迭代数。目标值是 7×7 采样的加权光斑残差、焦距误差和尺寸罚项的平方和，未接受的试步保留原指标。固定材料；有限差分 Jacobian、阻尼最小二乘、边界投影；局部结果不保证全局最优。

最终报告用 33×33 采样列出逐视场前后 RMS、权重与停止原因，可导出完整 JSON 轨迹和候选。报告中的优化采样曲线与最终复核指标分开标注。达到迭代上限和步长收敛均不代表约束通过。

记录版本时保存该版本的画质预设；恢复时恢复预设。旧版本没有预设记录时视为均衡。历史候选验收并不缓存为永久认证，重新计算后再判断。

## 无法采纳时

0.5 候选检查表受 `.candidate > div` 的 flex 样式影响，说明文字与长表被放进同一横排；失败项还可能位于可滚动表格的其他部分。仅靠截图不能断定原处方究竟哪项失败。

0.6 为检查表使用独立布局，并在表格上方直接列出全部阻止采纳的项。只要有失败，默认仅显示失败项；可切换显示全部，失败项始终优先。按钮提示与汇总使用同一检查数据。全部检查通过且引擎批准时才启用采纳；若引擎拒绝却没有失败项，会明确显示状态不一致并要求重新计算。

表格增加余量、更多有效数字与连续检查说明。最薄实体/空气间隔显示的是采样估计，而通过与否取决于完整半径上的连续区间认证。因此数值经四舍五入后看似达到下限，也可能仍不能认证；不会把安全约束放宽为采样估计判断。焦距、总长、中心厚度、像距和变量边界均逐项报告，最终通光检查涵盖全部配置视场与波长。失败光线不当作零误差。

## 离线真实玻璃

“镜片 / 面 → 查找真实玻璃材料”内置 8 种 SCHOTT 材料：N-BK7、N-BAK4、N-SK16、N-LAK22、N-F2、N-SF5、N-SF10、N-SF11。支持名称、nd、Vd 范围过滤；nd、Vd 按 d/F/C 谱线从 Sellmeier 系数计算，供选择与解释色散。

每次仅替换选中的玻璃实体，原有共享材料不会被全局改写。空气和独立光阑不能替换为玻璃。系数、有效波段和来源完整复制到项目；当前波长超出有效范围时禁止应用。不计算温漂、吸收、镀膜或材料自动替换优化。

数据取自 [refractiveindex.info 数据库](https://github.com/polyanskiy/refractiveindex.info-database)，CC0-1.0；原始参考 SCHOTT 2017-01-20b 目录，293 K。固定提交 `c5c2f188e848453def5970e347399d653df2ffc2`，各条 SHA-256 见 `src/data/glass-catalog.json`。再生成脚本 `scripts/import_glass_catalog.py` 默认复用固定提交。许可副本随源码和安装包分发。保留引擎的空气 n=1 近似；这些是标称目录系数，未实现熔次或温度修正。

验证记录见 [TEST_REPORT.md](TEST_REPORT.md)。
