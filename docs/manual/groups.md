# 多镜片编组与整体移动

入口：「设计 → 镜组管理」。整枚镜片/胶合组由材料连续段识别；这里的命名镜组可以包含多枚相邻镜片及其间隔。

## 创建与选择

选择至少两枚相邻完整镜片，填写名称并创建组。范围内的光阑和空气间隔一起归组，不拆开胶合面。最多 20 个连续、不重叠的组。

点击已有组可定位其表面。组名和范围随项目保存；命名版本也保存当时的组定义。

## 检查移动候选

输入移动量，正值沿 +Z、负值沿 -Z。只改变组前和组后的空气间隔，组内曲率、材料、中心厚度和内部间隔保持不变；组外镜片和传感器位置保持固定。

先检查候选，连续分离或边界空气间隔不合格时拒绝。几何通过后应用并重新分析画质，支持撤销。几何移动可行不等于通光和成像质量仍可行。

第一面是固定坐标原点，包含第一面的组可保存和定位，但不能整体平移。要改变这种结构，需重新规划处方或独立编辑间隔。

新增、复制或删除表面时会清空旧镜组，避免面号错位。恢复版本时恢复该版本的编组，旧扫描会按其源处方判断是否过期。
