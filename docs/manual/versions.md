# 持久化版本与同条件对比

入口：「交付 → 版本对比」。顶部「记录版本」可立即保存当前处方快照，命名和备注可在版本面板管理。

## 记录与恢复

保存当前为版本不会另存磁盘文件，需要再「保存项目」才能跨会话保留。最多 20 个版本，每个包含独立处方与当时镜组，不嵌套版本历史。删除版本不改变当前镜头；恢复版本会替换当前处方，可撤销。

设计目标、优化设置与扫描记录属于项目工作区；恢复不同光学处方后，旧扫描可能过期。候选也可以保存为版本，待进一步研究。

## 统一比较配置

选择 A、B，当前设计也可作为其中之一。视场定义、波长及权重、物距和传感器不一致时，需要明确勾选「仅在此次计算中将 B 统一为 A 的配置」。该对齐只用于计算，不偷偷改写保存版本。

按像高比较代表相同画面位置，不同设计可能需要不同物方角度；按角度比较则代表同一物方方向。报告保留实际角度与像高。

## 对焦条件

- 共用 A 的绝对平面像面：A/B 使用同一个 Z 坐标，适合固定传感器位置比较。若该平面位于 B 末面之前，明确报错。
- A / B 分别自动对焦：各自寻找局部最佳平面，每个设计的所有视场仍共用一个平面。适合比较重新对焦后的潜力，不应与固定像面结果混为一谈。

点击「计算同尺度对比」重新执行 33×33 几何分析。点列图共享尺度。之后可计算所选视场的多色 PSF / MTF 对比；两边使用同一个显式衍射模型。

PSF 比较转换为共同物理窗口和强度密度，MTF 使用同一 lp/mm 频率轴，不通过分别拉伸图像隐藏差别。导出报告记录实际计算处方、像面、配置、方法、采样、覆盖与收敛结果。
