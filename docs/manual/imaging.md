# 测试图近似成像

入口：「画质 → 测试图成像」。选择网格、分辨率条纹或点光源阵列，指定「成像衍射模型」，点击「计算多色测试图」。

## 结果代表什么

每个视场用对应多色 PSF 对局部平面测试目标卷积，采用周期延拓和局部平移不变假设。结果用于理解光斑、衍射和方向分辨率如何改变局部细节。

不是把整张照片通过完整镜头渲染，也不从普通照片推断真实物距、景深或散景。当前不提供完整整幅空间变化卷积与畸变重映射。不同视场小图的物理范围可能不同，应阅读每幅标尺，不只比较屏幕像素大小。

## 方法和失败

小视场可用快速法；大视场选「直接 Kirchhoff · 离轴平面像面」。每个配置视场分别进行衍射适用性和收敛检查，成功与失败分别展示。

某个视场没有图像时，查看该场诊断，不以其他视场图像替代。几何通过但衍射失败可能来自相位/窗口采样，不等于镜头完全不通光。模型与限制见[PSF / MTF](diffraction.md)。

修改波长、像面或光学处方后需要重新计算。若想判断固定传感器下的改进，应在[版本对比](versions.md)统一像面和测试条件。
