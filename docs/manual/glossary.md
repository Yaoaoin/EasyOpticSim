# 光学术语与单位速查

- EFL / 有效焦距：由系统光焦度定义，不等于总长或末面到传感器的距离。
- BFL / 后焦距：无限远近轴焦点到末面顶点的有符号距离。
- 像距：最后一面到当前平面传感器的间隔；通过自动对焦可改变。
- 入瞳 / Entrance pupil：从物方观察光阑的近轴像；出瞳是从像方观察的像。
- F 数 / F-number：有效焦距除以入瞳直径。显示值为近轴规格，有限物距不是已校正工作 F 数。
- 光阑 / Aperture stop：限制轴上光束的指定表面；有效口径用于物理裁剪。
- 半视场 / Field angle：光轴到一个物方方向的夹角；全视角通常为两倍对称半视场。
- 像高 / Image height：平面传感器上参考主光线的径向位置，单位 mm。
- 主光线 / Chief ray：瞄准实体光阑中心的光线；边缘光线瞄准光阑边缘。
- 曲率 / Curvature：c=1/R，单位 1/mm；R 为有符号曲率半径，单位 mm。
- K：圆锥常数，无量纲。偶次非球面 A4-A10 乘 r 的对应次幂，单位随幂次变化。
- 矢高 / Sag：曲面相对顶点的轴向位移 z(r)。
- RMS 光斑半径：关于质心的均方根半径，界面单位 µm，越小通常意味着几何像差越小。
- OPD / 光程差：实际波前相对参考球的光程差；波前 RMS 可用 mm 或波长数表示。
- PSF / 点扩散函数：理想点目标经过系统后的像面强度分布。
- OTF / 光学传递函数：PSF 的复频域表示；MTF 为归一化 OTF 的幅值。
- S / Sagittal：弧矢 X 方向；T / Tangential：子午 Y 方向。
- lp/mm：每毫米线对数；不能直接等同于单个像素的像素数。
- 遮光比例：按发射样本计数的物理裁剪，不等于精确相对照度。
- 采样收敛：增加采样后结果变化低于门槛；只说明指定模型与配置的数值稳定性。
- 常用换算：1 mm = 1000 µm；1 µm = 1000 nm；rad = 度 × π/180。
