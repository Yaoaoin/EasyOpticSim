# 光圈扫描与最佳档位

入口：「调校 → 光圈扫描」。扫描不直接改变当前处方，先产生记录，再复核候选。

## 设置扫描

输入 F 数列表，最多 12 档，范围 0.5-128；选择几何采样。「每档重新对焦」取消时使用源处方的同一像面；选中后每档独立进行全视场 RMS 自动对焦，不沿用前一档结果。

指定 F 数由近轴入瞳映射为实体光阑半径。光阑机械边界必要时同步扩大，其他镜片不会自动扩大。因此显示实际 F 数仍不保证大光圈能通光。

需要衍射时勾选「逐视场多色 MTF」，再选择「扫描衍射模型」。全档使用相同模型；大视场需要直接 Kirchhoff。它会明显增加计算时间，失败视场记录原因，不会自动换另一种模型。

## 阅读结果

每档包含实际 F 数、最终像距、逐视场 RMS、失败/总样本数、瞄准失败和物理遮挡。可选 MTF 记录弧矢/子午 10、30 lp/mm 及收敛信息；频率不在有效网格中时显示未定义。

推荐档仅按全部采样无失败时的几何 RMS 选择，不是综合衍射后的最佳光圈。缩光圈可能降低几何光斑，却因衍射降低高频 MTF。

## 保存和采纳

完整源处方、设置和摘要随项目保存。光学处方改变后旧记录仍可查看和导出，但会标记过期，不能直接采用。旧版无覆盖记录的扫描需重算才能判断传感器覆盖。

选择一档，点击「复核并生成所选光圈候选」；软件重新执行 33×33 追迹和约束检查，通过后才可采纳。固定像面与每档重新对焦的扫描不是相同条件，报告和对比中要保持明确。
