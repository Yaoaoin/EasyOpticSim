# 搭建镜头、整枚编辑与专业表面

## 从实体镜片开始

左下选择双凸、平凸、双凹、弯月或胶合双片，点击「添加镜片」。软件插入一整组表面和空气间隔。也可添加单个表面，适合专业处方录入。当前最多 100 个表面。

选择左侧透镜后，在右侧基础模式编辑材料、中心厚度、镜后间隔、有效直径、机械外径和前后面形状。胶合组共享中间光学面，修改时保持连续材料结构。复制和删除整组会同时处理光阑索引和后续位置；表面数量改变时清空旧镜组与优化变量，避免引用错面。

## 曲率和材料约定

专业模式中曲率 c 的单位为 1/mm，曲率半径 R=1/c。c=0 是平面；正曲率表示球心位于顶点 +Z 侧。从左向右追迹，因此通常双凸镜前面正、后面负。不要把半径 mm 直接填入曲率框。

每面「面后材料」表示通过该面后所处的介质，空气通常为材料 0。独立正透镜一般为：前面后玻璃、后面后空气；胶合双片则依次为玻璃 A、玻璃 B、空气。材料顺序错误会显著改变光焦度。

厚度是当前面顶点到下一面顶点的距离；最后一面的厚度是到传感器的距离。第一顶点固定为 Z=0，其余坐标逐项累加。半口径是有效半径，不是直径。

## 非球面和光阑

专业模式提供圆锥常数 K 与 A4、A6、A8、A10。系数分别乘以 r 的 4、6、8、10 次幂，长度单位为 mm。很小的系数在大口径上也可能产生很大矢高，建议逐项修改并检查定义域和几何。

点击「设为光阑」指定实体光阑所在表面，可与折射面重合。只改变光阑索引不会自动改变其他有效口径。摄影区的光阑滑块修改该面的有效半径；实际可用通光仍取决于全部表面。

## 机械边缘

机械外径和有效直径分开编辑，可制作带方边环带的“折角”镜片。环带只改变实体轮廓，超出有效口径的光线依然被挡住。参见[机械与几何检查](mechanics.md)。

编辑后可 Ctrl+Z 撤销；先保存版本再尝试较大改动。焦距是计算结果，不能通过画布缩放或目标焦距输入直接实现。
