# 一键镜头体检与安全修复

入口：「检查与保存 → 一键镜头体检」。点击「开始完整体检」后，EasyOpticSim 按固定顺序完成项目完整性、曲面与间隔、光线瞄准与通光、33×33 几何画质、焦点与目标，以及中心/边缘快速 PSF / MTF 检查。大视场自动使用离轴平面像面模型；计算可以取消，取消后不会沿用未完成结果。

## 五张结果卡

- 能否成像：确认有效焦距、焦点方向与逐视场像点。
- 是否通光：区分追迹失败和遮挡比例；遮挡比例不是相对照度。
- 画质是否达到目标：比较逐视场 RMS、用户设置的画质上限和快速衍射收敛。
- 机械结构是否可实现：使用连续分离检查；不代表加工公差、强度或装配认证。
- 是否适合导出：只要前四类存在阻断项，就明确标为必须修复。仍可保存草稿，但不可把草稿写成正式通过。

结果分为「可以继续」「建议改进」「必须修复」「尚未检查」。系统不会用一个含糊总分掩盖阻断项，也不会把高成本或失败的检查当成通过。

## 智能建议的安全边界

「生成自动对焦候选」和「生成改进候选」复用现有候选机制：先计算、显示前后 RMS 和完整约束表，只有全部采纳条件通过时按钮才可用。用户点击「采纳候选」之前，当前处方不变。几何相交、口径和遮挡问题只会定位问题面或打开对应工具，不会静默扩大镜片、移动表面或放宽目标。

体检报告可导出 JSON，包含五类结论、当前项目与采样条件。报告只适用于记录的处方、视场、波长和模型，不是制造、公差、杂散光或真实相机系统认证。
