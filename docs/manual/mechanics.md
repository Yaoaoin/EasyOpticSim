# 机械边缘、尺寸和几何检查

## 光学口径与机械外径

有效口径限定参与光学追迹的区域；机械外径描述镜片实体边界，可以大于有效直径。基础模式按直径显示；原生格式 semi_aperture 和 mechanical.semi_diameter 均保存半径，单位 mm。

「方边环带」将有效口径之外的轮廓保持为边界矢高，形成类似折角的肩部。「随曲面环带」将曲面延续到机械边界。未设独立边缘时，实体径向范围跟随有效口径。

环带不是可折射的额外光学区域，不会扩大实际通光。要增加光学口径，必须修改有效口径并重新验证。

## 检查顺序

在「设计 → 几何检查」查看每段实体或空气间隔。检查包括曲面定义域、中心厚度、边缘厚度、两面相交与连续分离状态。点击诊断可定位到对应面。

中心厚度只测轴上；即使中心为正，边缘仍可能相交。最薄数值是采样估计；通过状态使用引擎的区间检查，二者含义不同。处于数值边界或无法证明分离时会保留未通过诊断。

机械尺寸变大可能使此前有效的光学面超出定义域，或导致实体相交，应修正曲率、中心厚度、外径或边缘形式。不要只调大有效口径来消除遮挡而忽略实体厚度。

## 与优化和图纸的关系

约束优化可以限制中心厚度、最薄实体和最小空气间隔。图纸分别记录有效直径、机械直径、轴向长度、采样最薄值和连续检查状态。几何通过不代表通光和像差通过。

当前不提供加工倒角、胶层厚度公差、装配基准、机械强度和完整公差链。技术图纸是名义光学设计记录，未指定项目不会自动补全。
