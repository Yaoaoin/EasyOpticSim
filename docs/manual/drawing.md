# 技术图纸 PDF 导出

入口：「交付 → 技术图纸 PDF」，或顶部「文件与导出 → 导出技术图纸 PDF」。图纸在本机生成，中文字体已随软件提供，无需 Python、打印机或网络。

## 操作步骤

1. 保存当前项目或记录基准，确认项目名称和处方。
2. 预览总剖面；需要波动结果时勾选「加入逐视场多色 PSF / MTF」，明确选择快速或直接 Kirchhoff。
3. 点击「导出技术图纸 PDF」。软件冻结当前处方，重新计算几何、实际视场和 33×33 几何分析；不会自动重新对焦。
4. 若勾选衍射，以同一种方法对全部视场做多色 256 上限分析。失败场记录原因，其余场可继续。
5. 完成后选择 PDF 保存位置；取消保存不会改变项目。计算阶段可取消。编辑设计或离开图纸页会终止尚未完成的导出。

## 图纸内容

- 总览：项目说明、时间、有效焦距、后焦距、近轴 F 数、传感器、物距、光阑和源项目哈希。
- 总装剖面：等比例矢量轮廓、首顶点至像面长度、光阑与像面位置。
- 逐镜片/胶合组分图：局部等比例剖面、面号、轴上长度、机械包络最大直径。胶合内部各段厚度和各面直径见处方表。
- 全部表面：顶点 Z、半径与曲率、间隔、有效直径、机械直径、环带形式和面后材料。
- 全部非球面系数：K、A4、A6、A8、A10，包含零值和单位。
- 材料快照：常数折射率或 Sellmeier、有效波段、完整系数与来源。
- 视场、光谱、像面、覆盖状态、点列/色差/畸变摘要、瞳参数、几何分离和诊断。
- 可选逐视场 PSF 图、S/T MTF 曲线、方法和收敛参数。
- 镜组、版本摘要、目标和优化/扫描设置；历史扫描明确属于其源处方。

## 精确源数据与附件

PDF 内嵌 project.oos.json（完整项目）与 analysis.json（本次结果摘要）。源项目保存未舍入数值、所有版本与历史扫描；总览 SHA-256 对应该附件的 UTF-8 字节。用支持附件的阅读器提取后，可重新在 OOS 打开。摘要省略大型光线、点列和 PSF 数组，不是完整重新积分所需的瞳数据集。

PDF 文本可检索，矢量剖面缩放不失真。中文名称可显示；字体未收录的少数字符会用问号替代，精确源文本仍保留在附件。图形按各页视窗缩放，尺寸以数值为准，不从打印图形量取。

## 图纸的工程范围

它是一份名义光学技术记录。未指定的加工公差、倒角、胶层、表面质量、镀膜、装配基准和强度不会凭空补全，不可直接作为完整加工验收图纸。几何/追迹有问题时仍可导出草稿，首页及检查页明确标注；未算 MTF 也会明确记录。
