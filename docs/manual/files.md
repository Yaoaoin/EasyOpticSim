# 项目文件、保存与数据交换

## 新建、打开和保存

「新建项目」可选择空白或教学模板，设置名称、传感器、无限远/有限物距和传感器联动视场。空白项目先添加镜片，再进行光学分析。

「打开」接受原生 .oos.json 与 OOS 处方 CSV。结构合法但几何存在问题的草稿可以打开修复。无效数值、错误材料索引、不支持的格式版本会明确拒绝。

「保存项目」写回当前原生文件；「文件与导出 → 另存为项目」选择新位置。CSV 导入后首次保存为新的原生项目。原生桌面保存先写同目录临时文件、同步后原子替换；取消对话框不会写入。

## 保存哪些内容

原生项目包含全部表面、材料快照、光阑、物距、传感器、视场与波长。工作区还可保存命名版本、对焦设置、优化变量和约束、镜组、光圈设置及完整扫描摘要。大型 PSF 数组、临时点选瞳面光路和对比计算不会塞入项目文件，需要重新计算或单独导出报告。

文件上限 4 MB，命名版本最多 20 个。版本不嵌套历史。达到限制时删除不需要的版本，或另存为独立项目；不要手动截断 JSON。

## 格式兼容性

1.0 继续读取 v1/v2/v3。独立机械边缘需要 v2；像高视场及新画质保护使用 v3。新软件不会将 v3 编辑成 v2。旧软件可能不支持 v3，应保留原始文件副本。

OOS CSV 第一行 #oos 元数据保留材料与工作区，后续是表面表格。它不是通用商业光学处方格式；删除元数据会丢失重建完整模型需要的信息。导出报告 JSON 是结果记录，不应当作原生项目打开。

## 自动恢复和版本

每次编辑会尝试写入本机自动恢复，启动时优先恢复。它不等于外部文件已保存，也不应代替手动保存。命名版本和撤销历史不同：撤销栈属于会话，命名版本保存在项目内。参见[版本对比](versions.md)。

## 技术图纸与源项目

PDF 附件 project.oos.json 是导出时冻结的完整源数据，含原始精度；它的 SHA-256 写在总览页。支持附件的 PDF 阅读器可提取后在 OOS 打开。analysis.json 记录本次分析摘要，省略大型光线/点列/PSF 数组。详见[技术图纸](drawing.md)。
