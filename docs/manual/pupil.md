# 可交互瞳面图与光路定位

入口：「画质 → 瞳面图」。本图显示实体光阑平面上的规则圆盘采样，不是出瞳波前或相对照度图。

## 操作

选择视场、波长和采样数，执行计算。界面提供 9、13、17、25、33 等奇数网格；更密采样有助于发现边缘遮挡，但不是任意瞳拓扑的完整证明。

- 绿色：成功到达像面。
- 红色：物理追迹终止，查看终止面和原因。
- 黄色：瞄准未解，查看目标光阑坐标、残差和试算诊断。

点击样本或用方向键选择，中间剖面高亮对应实际光路，并联动表面。剖面是 Y/Z 投影；离子午面的 X 坐标在瞳面图及数据中查看。

## 排查方法

整片红色通常需要检查某面有效口径、材料或几何；边缘红色可能是实际遮挡；黄色需要检查瞄准收敛，不能直接视作镜片挡光。缩光阑可能改变问题，但不要以缩小后通过来证明原始大光圈也可用。

不同波长和视场应分别检查。这个图的成功比例按采样点计数，不包含能量权重、Fresnel 损失、镀膜或传感器响应；不能作为精确照度。
