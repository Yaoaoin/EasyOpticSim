# 报错排查与常见问题

## 显示无法采纳，但表格看起来都通过

先读候选顶部的「无法采纳」原因汇总。检查表默认显示未通过项，可切换过滤查看全部。引擎批准状态、细采样通光、变量边界、阶段完成与连续几何检查都可能阻止采纳；表格舍入值为 0 不表示实际边界一定满足。其他通过项不会抵消失败项。

## 设置了全画幅，为什么角落仍未验证

传感器大小与测试视场是不同设置。到「设计 → 设计目标」显式选择传感器联动或角落像高，重新计算。旧项目保留原角度，旧扫描缺少覆盖记录时必须重算。参见[视场与覆盖](fields.md)。

## 视场反求或瞳瞄准失败

检查处方是否先能在轴上成像，检查曲率符号、玻璃/空气顺序、有效口径、光阑位置和几何。逐步增加视场以定位失效区间。瞄准失败不等于已证明物理遮挡；黄色瞳点没有真实光路，不应通过画一条直线来掩盖。

## 焦距、F 数与目标相差很大

目标不会自动实现设计。曲率输入为 1/mm，基础镜片半径则为 mm；注意两者区别。400 mm f/2.8 需要约 142.86 mm 的近轴入瞳，仅按商品示意图复制形状、用通用材料和小前径不会复现商品性能。

## 后焦距为负或自动对焦拒绝

无限远负后焦距表示后方近轴实像条件不成立。先调整处方而不是不断增大像距。自动对焦只改变当前最后一段空气距离，不能把任意错误镜头变成实像系统。

## MTF 超出模型或数值不收敛

快速模型有独立小视场限制，大视场需选择直接 Kirchhoff。直接法也会拒绝复杂瞳映射、Nyquist 不足或能量窗口不足。先检查焦点、遮挡和色差，再尝试 256 采样。不能以更大数字上限代替验证。

## 保存后结果不见了

处方、版本、镜组和光圈扫描摘要会保存；临时 PSF、瞳点和部分分析曲线需要重算。结果报告 JSON 与原生项目用途不同。磁盘文件是否保存看项目名旁状态，不看自动恢复提示。

## PDF 未生成、取消或只有草稿

计算可取消；保存对话框取消不写文件。几何与波动失败会写进图纸诊断而非冒充通过。PDF 上限 32 MB；项目附件上限仍受原生 4 MB 约束。换成较短项目名称也可排除系统路径问题。

## 界面区域太小或滚动错位

收起暂时不用的侧栏，恢复布局，或调整左侧透镜/表面比例。独立滚动区只移动自身；工作台导航固定在中央上方。Ctrl+K 可直接找到被收纳的工具。建议桌面窗口至少 1000×720，适当调低过大的系统显示缩放。
