# 视场、传感器和覆盖检查

入口：「设计 → 设计目标 → 视场与传感器」。右侧「摄影与分析」也可修改同一份传感器宽高。

## 三种视场定义

- 按物方角度：直接指定半视场列表，界面用度，内部用 rad。适合明确物方方向的对比。
- 跟随传感器：生成中心、短边中点、长边中点、画面角落四个检查位置。
- 按目标像高：输入毫米列表，例如 0, 12, 18, 21.63330765，点击「应用目标像高」。最多 15 个视场。

新建默认启用传感器联动。旧项目保留原来的角度配置，必须显式切换；输入 36×24 mm 本身不会把旧的三角度分析变成全画幅分析。

## 实际像高反求

理想估计为 θ=atan(h/EFL)。35 mm、36×24 mm 的理想短边/长边/角落半视场约为 18.92° / 27.22° / 31.72°。存在畸变时这些不是实际测试角度。

OOS 沿当前设计的主光线分支反求在当前平面像面上到达目标像高的物方角度。修改材料、间隔、物距或像面后会重新求解。反求失败会报错，不能以理想角度替代。参考波长取配置中最接近 d 线者。

## 如何解释覆盖报告

- 未验证：没有与目标检查位置匹配的实际测试点。
- 求解未完成：主光线或部分瞳光线无法可靠求解。
- 存在物理遮挡：实际追迹被光学口径裁剪。
- 声明采样通过：这个检查点的配置波长和几何采样没有失败。

匹配像高容差为 0.002 mm。测试更远的像高不自动证明中间位置通过。声明采样通过不表示像差良好、整个像圈连续通过或 MTF 收敛；MTF 状态单独记录。通过比例不是精确相对照度。

## 范围和常见误区

几何输入边界 ±0.7 rad，约 ±40.107°，不保证任意设计都可在该范围求解。快速衍射模型仍只有 ±8.59°；大视场须单独选择直接 Kirchhoff，并通过其适用性和收敛检查。

按像高比较两个镜头时，实际物方角度可能不同，这是相同画面位置的比较。按角度比较时，实际像高可能不同。报告同时保留这些条件。参见[版本对比](versions.md)。
