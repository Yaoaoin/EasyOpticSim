# 新手教程：完成第一份镜头设计

适用版本：OpenOpticSim Y1.0。软件在本地运行，无需账户；保存项目和计算不依赖网络。建议首次使用从简单模式和教学示例开始。

## Y1.0：从一句话目标开始

点击顶部“新建项目”，先选择拍人像、拍风景、拍远处或拍近物，再确认效果并选择一个可计算的教学起点。向导会建立正式的传感器、视场、物距、焦距和 F 数目标；这些是目标，不会把示例处方静默改造成已经达标的镜头。

默认“简单”模式把流程整理为“告诉我想拍什么、搭建镜头、让画面更好、检查与保存”四步。需要镜组运动、光圈扫描、瞳面、版本比较等完整工具时，在顶部切换“专业”；切换不会重开或修改项目。

## 第一步：打开示例并保存副本

点击左下角「示例与学习」，打开「双胶合探索」或「400 mm · 传感器覆盖工作区」。示例中的观察任务介绍它适合研究什么；400 mm 工作区为修正后的小光圈实验设计，不是佳能商品镜头处方。

顶部「文件与导出 → 另存为项目」保存自己的 .oos.json 副本。也可「新建项目」从空白或模板开始。打开另一个项目前，软件会询问是否保存未保存的编辑。

## 第二步：认识工作区

左侧分别选择整枚镜片与单个表面；中间是子午光路和分析工作台；右侧分为「镜片 / 面」与「摄影与分析」。四组工作流程为「设计、画质、调校、交付」，每组下方列出对应工具。使用 Ctrl+K 查找功能，F1 打开当前页面帮助。

左侧、中央和右侧独立滚动。透镜列表与表面列表还可以分别滚动；拖动中间分隔条调整两者比例。上方按钮可收起侧栏和恢复布局。

## 第三步：确认目标和传感器覆盖

在「设计 → 设计目标」设置传感器尺寸和视场定义。第一次练习可沿用示例，不必立刻切换全画幅角落。需要检查整个传感器时选择「跟随传感器：中心、边中点与角落」。查看每个检查点是通过、遮挡、求解失败还是未验证。

改变目标焦距不会直接缩放镜头。有效焦距来自实际曲率、材料和间隔；目标供优化器约束使用。参见[视场与传感器](fields.md)。

## 第四步：调节光圈并对焦

右侧「摄影与分析」修改光阑半径，按 Enter 或移出输入框提交。拖动光阑时显示低采样预览，停止后重新精细计算。光阑半径不是入瞳半径；显示的 F 数按近轴入瞳计算。

先在「设计 → 几何检查」排除相交，再到「画质 → 像差与通光」查看失败光线。点击右侧「自动对焦」生成候选，查看复核结果，全部通过后「采纳候选」。没有采纳时，当前镜头不会改变。若存在虚像或求解失败，对焦本身无法修复它们。

## 第五步：查看画质

在「画质 → 点列图」观察中心和边缘的光斑。进入「PSF / MTF」，先选中心、多色和快速模型；大视场改用直接 Kirchhoff。点击计算，检查收敛状态，再比较边缘。不能把几何 RMS 小等同于 MTF 一定高。

「测试图成像」显示各视场局部平面测试目标经过 PSF 后的近似图像，不是完整三维摄影场景。参见[衍射分析](diffraction.md)和[测试图成像](imaging.md)。

## 第六步：保存基准、尝试修改

顶部「记录版本」保存当前设计基准。修改一项参数后，在「交付 → 版本对比」选择 A/B，统一测试条件，计算同尺度结果。撤销 Ctrl+Z、重做 Ctrl+Shift+Z 用于当前会话；命名版本随项目文件保存，适合跨会话回看。

## 第七步：导出和重开

「交付 → 技术图纸 PDF」导出完整名义处方与图纸。需要重新编辑时保存 .oos.json；PDF 本身也内嵌一份精确源项目。保存后用「打开」重新载入，确认处方、视场、版本和镜组仍在。

进一步学习：[编辑镜片](editing.md)、[对焦扫描](focus.md)、[光圈扫描](aperture.md)、[约束优化](optimization.md)。遇到红色提示先查[报错排查](troubleshooting.md)。
