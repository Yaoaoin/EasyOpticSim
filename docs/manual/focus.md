# 自动对焦与对焦扫描

## 自动对焦

右侧「摄影与分析 → 自动对焦」只搜索像面位置，不改变镜片曲率、材料或光阑。算法在当前像距与正近轴后焦距给出的有界区间内搜索，不保证找到任意系统的全部焦点。

输出候选和几何、规格、通光复核；点击「采纳候选」后才改变当前像距。若无法采纳，查看失败原因列表，而不是只看部分通过的约束。

## 对焦扫描

入口「调校 → 对焦扫描」。设置像距最小值、最大值、扫描步数、瞳采样以及中心/全视场 RMS 准则，执行扫描。这里的像距是最后一个表面到平面传感器的距离，不是有效焦距。

中心准则需要存在 0 rad 视场。全视场准则综合所有配置视场；候选仍要求所有配置视场和波长满足通光与约束。不能用一个成功中心视场掩盖边缘失败。

曲线逐视场展示光斑变化；推荐点是离散网格最佳点，不是无界连续最优。推荐点位于扫描边界时应扩大区间再算。点击曲线或选择扫描位置后，复核生成候选，再决定采纳。

## 可靠使用

先保存基准版本；排除相交、负后焦距和瞄准问题；先用较粗扫描确定焦区，再缩小范围。对焦扫描设置随项目保存，临时曲线可能需要重算。

修改当前光学设计后，旧候选失效。取消不改写处方。像高视场随像面移动会重新求角度，因此报告保留每点实际视场。比较固定物方方向时应使用角度视场。
