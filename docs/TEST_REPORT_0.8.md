## 400 mm 扫描结果

固定像距 388.786311 mm，17×17、3 视场 × 3 波长，每档 1,773 条样本：

| F 数 | 失败数 | 几何 RMS 均方 µm | 多色 MTF 收敛视场 |
|---|---:|---:|---:|
| 4 | 1,596 | 无有效评分 | 0/3 |
| 8 | 1,164 | 无有效评分 | 0/3 |
| 11 | 639 | 无有效评分 | 3/3 |
| 16 | 0 | 10.606995 | 3/3 |
| 22 | 0 | 9.038597 | 3/3 |

f/11 的波动计算支持被裁剪瞳，并不表示通光已通过；单位能量 PSF/MTF 不代表相对照度。f/22 的几何光斑更小，也不代表所有空间频率上的 MTF 更高。f/16 与 f/22 独立重新对焦后的像距分别为 388.789088、388.900078 mm，对应 RMS 10.606717、8.853571 µm。最佳档选择只针对声明采样和几何目标，不作任意镜头的保证。

## 独立光学对照

- RayOptics 0.9.10：6 个既有模型、378 条显示光线；最大交点差 `9.9741e-11 mm`。
- RayOptics 独立重追、参考球 OPD、NumPy FFT/复杂 OTF：5 个既有算例和 400 mm f/16 的 3 个多色视场均通过既有阈值。最大 OPD 差 `3.1475e-10 mm`，最大 MTF 绝对差 `1.2386e-7`。
- 两份局部成像各 65,536 像素，与 NumPy 卷积的 8 位输出最大差为 0；修正版平均能量差 `1.67e-15`。

报告：[几何](validation-rayoptics.json)、[波动/成像](validation-diffraction-0.8.json)。共用导出入射位置与孔径掩码；不是对所有瞳拓扑的穷尽认证。标量传播、均匀投影瞳振幅和局部平面卷积范围保持不变。

## 实际界面验收

开发浏览器连接真实 Rust 0.8 引擎，34 面、16 枚/组的用户 400 mm 处方：

- 加载五档扫描，结果保留失效原因和几何评分；不因跨语言 JSON 属性顺序误判过期。
- 目标 F 数从 16 改为 2.8，提示所需入瞳 142.86 mm 与当前前口径 70 mm 的限制；显示 F 数误差具体失败项。当前设计检查还附带现有几何预览通光，候选另以 33×33 复核。
- 修正版边缘视场 d 线 13×13 的 113 个点均通过；点选边缘光线后剖面高亮实际路径。原始版本同采样为 57 通过、4 物理遮挡、52 瞄准未解；点选未解采样，画布没有高亮物理路径，并定位到目标 S15。
- S3–S6 平移 1 mm 被负间隔检查拒绝；0.01 mm 通过，前/后边界间隔变为 60.01/0.09 mm。应用后旧扫描明确过期，撤销后恢复有效。
- 实际创建 S7–S10 新组，记录命名版本；切到原始版本再恢复，两个组均恢复。
- 取消扫描保留原有五档完整记录。重新运行 f/16、9×9、多色 MTF 后，三个视场全部通过 64→128 收敛检查。
- 扫描候选经 33×33 复核，58/58 项通过，采纳启用。实际下载后用文件选择器重开，34 面、2 个编组、3 个版本、像距/光阑两个优化变量以及三个视场 MTF 完整保留。保存的扫描再次计算后完整 JSON 相同；加入这些元数据后几何、波动和成像完整 JSON 与 0.7 基线相同。
- 重开后切换每档重新对焦，f/16 像距更新至 388.7891 mm。优化过程中修改目标、扫描候选复核时修改约束，旧任务被取消且没有迟到候选回填；撤销/重做、加载文档也同步更新候选有效性。
- 当前目标检查与其输入修订绑定，计算未完成时明确显示待检查，不沿用旧通过状态。完整重载后界面正常，控制台无错误；开发期间修改 effect 依赖数组产生过一条 Fast Refresh 告警，完整重载后不复现，单独保留在 UI 记录中。
