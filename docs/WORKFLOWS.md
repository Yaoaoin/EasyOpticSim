# OpenOpticSim 0.4：对焦、版本与约束设计

## 推荐流程

打开一个示例 → 记录基准版本 → 对焦扫描 → 复核候选 → 保存候选版本 → 同尺度对比 → 采纳 → 保存项目。也可直接打开 `examples/version-workflow.oos.json`，其中保存了原创双胶合镜头的多色对焦基准与像面后移 0.05 mm 两个版本。

## 对焦扫描

“对焦扫描”页的像距是**最后一个表面顶点到平面传感器的轴向距离**，单位 mm。范围 0.01–100000 mm，3–101 个等间隔位置；瞳采样为奇数 7–33，UI 提供 9/17/25/33。

- 全视场均方折中：对每个视场的多色 RMS 平方取等权平均，再开方；波长按项目权重计算。
- 中心优先：使用 0 rad 视场的多色 RMS，项目必须包含 0°。其余视场仍显示曲线并参加通光检查。
- 任一视场存在遮挡、追迹失败或没有有效 RMS，该位置不参与推荐；失败不算作零误差。
- 推荐点是离散扫描点，不是连续全局最优。若最低点在边界，应扩大范围；想获得更细分辨率，应缩小区间重扫。
- 用滑杆或数据表选择位置。“复核并生成对焦候选”以 33×33 采样复核原设计和候选；显示的候选前后 RMS 均是全视场均方值。未点击采纳时处方不变。
- 可展开所选位置的 PSF/MTF，使用原有标量衍射适用性与收敛检查，不能用几何 RMS 替代衍射评价。

成功扫描后设置随项目保存；扫描曲线本身可导出 JSON 报告，不作为项目缓存保存。取消不改动处方。修改处方、选项或切换页面会取消页面计算并清除过期结果。

## 版本库和对比

“记录版本”创建默认名称，可在版本页重命名。也可以直接填写名称后点击“保存当前为版本”；优化或扫描候选可在采纳前单独保存为版本。

每个版本保存处方、材料、视场、光谱、物距和传感器，以及名称、时间、备注。最多 20 个版本，项目总大小限制 4 MB。版本不包含其他版本，避免历史递归增长。记录版本后须保存项目文件；本地自动恢复仅是额外的恢复副本。

版本删除和恢复均支持撤销。恢复处方保留当前版本库和工作区设置；优化约束是当前工作区的设置，不会因恢复某个处方而被暗中替换。版本备注保留候选说明；完整优化检查需重新运行，不把历史备注当作新的约束认证。

A/B 可分别选择保存版本或当前设计。对比每次重算，统一使用 33×33 几何瞳采样。若视场、波长/权重、物距或传感器不同，先提示差异并禁止直接比较；勾选“仅在此次计算中将 B 统一为 A 的配置”后，使用临时副本重算。原始版本与当前处方均不改写。

- 点列图：两边共用由全部点决定的物理范围，分别以各自多色质心为中心。显示失败/遮挡计数；存在失败时，RMS 只描述存活光线。
- PSF：统一 µm 视窗，单位总能量归一化，以像素面积换算为密度后使用共同峰值和同一线性/对数亮度映射；双线性重采样仅用于显示。图像中心分别是各自参考主光线，不表示绝对畸变相同。
- MTF：共用物理 lp/mm 横轴和 0–1 纵轴，A/B 用颜色区分，弧矢/子午用实线/虚线区分；不把不同像素间距下的数组下标当成同一频率。
- 衍射请求使用共同视场、完整配置光谱及 256 瞳采样上限。两边各自必须通过收敛门槛；实际收敛分辨率可以不同，并显示在图旁。任意一边失败时不展示一组不完整对比。

对比报告包含两份处方、公共配置、光学汇总、共同点列图范围、MTF、采样与收敛信息。为控制文件大小，不含完整光线路径、点列坐标和 PSF 数组。报告未保存在版本库内，可按需另行导出。

## 带约束的局部优化

在右侧“专业”模式中设置目标焦距、焦距绝对允许误差、最大总长、最小中心厚度、最小实体厚度（含机械边缘）和最小空气间隔。总长从第一面顶点量到像面，包含光阑前后间隔和最后像距；最小空气间隔包含独立光阑两侧，最后像距按轴向值检查。

变量可选当前面曲率、当前面后间隔、A4 与像距。CLI 可显式指定最多 12 个曲率、厚度或 A4–A10 变量。材料不参与自动替换。

局部阻尼最小二乘最多运行 25 次。光斑残差按 0.01 mm 归一化；焦距残差除以用户容差；尺寸违规惩罚除以相应尺度后乘 100。优化导数使用采样厚度，最终厚度检查使用连续区间分离算法。界面“实际最薄值”仍是采样估计；通过状态不能仅由该数值推断。间隔容差为 1e-9 mm，不能完成连续区间确认时按未通过处理。

最终前后 RMS 使用相同的 33×33 采样。任何失败/遮挡光线导致候选被拒绝；最终约束不全部满足时返回检查表并禁用采纳，允许保存为待改进版本。满足约束也不意味着 RMS 必然降低：目标焦距和尺寸约束可能带来权衡。系统不保证全局最优，也不替代强度、公差、加工或装配验收。

## 画布

滚轮围绕指针缩放，左键拖动平移；按钮支持放大、缩小、适应全部与聚焦选中镜片。焦点在画布时，方向键平移，`+`/`-` 缩放，`0` 复位。相同变换用于镜片、光线和像面；视图操作不改变处方、保存状态或光学计算。新建/打开文档时复位视图。

## 文件兼容与边界

继续读取光学模型 v1/v2；可选 `workspace.schema_version=1` 承载版本库和设置。原生 JSON 与带 `#oos` 元数据的 CSV 均保留工作区。更早的软件不能提供工作区管理，不应使用旧版工具重新生成这类文件。

原子保存、4 MB 限制、未保存保护保持生效。最近文件列表、跨进程保存路径记忆、任意制造边缘、整幅空间变化 PSF 成像、公差、材料自动选择和全局优化仍未实现。发布与验证边界见 [TEST_REPORT.md](TEST_REPORT.md)。
