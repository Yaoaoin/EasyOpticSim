## 衍射交叉验证

| 算例 | 独立有效光线数 | 最大 OPD 差 mm | 最大 MTF 绝对差 |
|---|---:|---:|---:|
| singlet_axis_stopped | 12,629 | 5.165e-11 | 2.190e-08 |
| doublet_offaxis_polychromatic | 27,855 | 6.598e-11 | 7.639e-09 |
| finite_asphere_offaxis | 12,482 | 6.450e-11 | 1.395e-08 |
| distant_finite_object | 12,476 | 6.474e-11 | 1.518e-08 |
| clipped_singlet_axis | 4,537 | 5.165e-11 | 2.826e-08 |

对照分别使用 RayOptics 0.9.10 的独立求交/折射、独立球面求交、NumPy 复瞳 FFT 与复 OTF、直接球面距离积分。有限物距入射相位另用 Decimal 50 位距离相减对照，覆盖 1e12 mm 物距。共同使用 OSS 发射坐标及口径掩码，不能视为对全部瞳拓扑的独立认证。

OPD、PSF 与 MTF 的高一致度说明两个实现对**相同标量模型**的计算一致，不能把这些误差当作任意真实镜头的物理误差保证。运行时收敛门槛、振幅假设、参考球近似和适用性见 [算法与范围](DIFFRACTION.md)。完整数据见 [机器报告](validation-diffraction.json)。

## 实际界面检查

- 双胶合示例自动对焦、采纳候选，切换到 5.73° 边缘视场和三波长分析。
- 衍射任务取消后可重新运行，取消结果不会覆盖新结果。
- 实际显示 64→128 瞳采样、MTF 变化约 0.0014、PSF L1 约 0.0329、边缘能量约 0.25%。

- 未对焦的单透镜被拒绝：显示 PSF L1 和相位步长超限原因及对焦/缩光阑建议，没有显示误导性 PSF。

## 性能

同一 Windows 机器、32 逻辑处理器；发布 CLI 包含启动、反解瞳采样、多波长 FFT 和完整 JSON 输出，三次取中位数。

- 双胶合三视场、三波长局部成像：约 0.76 秒。
- 示例单视场三波长衍射：约 0.21–0.96 秒，视采样级别与镜头而变。
- 大光圈单透镜边缘视场会被质量门槛拒绝；性能脚本也检查该预期行为。

详情见 [衍射性能记录](benchmark-wave.json)。不对其他硬件或任意复杂镜头承诺相同耗时。开发用未优化 Rust 构建明显更慢，以上为发布版。

## 仍待验收和实现

整幅空间变化卷积与畸变映射、真实透射振幅/照度和高 NA 矢量效应尚未实现；当前是局部平面目标模型。无 WebView2 的干净 Windows 机器断网安装、原生文件对话框完整流程、签名分发和真实新用户可用性尚未验收。远程 CI 尚未实际运行；本地已执行上述对应检查，CI 配置已加入衍射独立验证。
