## 独立光学对照

- RayOptics 0.9.10：6 个既有模型、378 条显示光线，最大交点差 `9.9741e-11 mm`。含有限物距与非球面；这项不单独证明瞳反解正确。
- RayOptics 独立重追与参考球 OPD、NumPy FFT/复杂 OTF：5 个既有算例加修正版 3 个多色视场，全部通过既有阈值；修正版最大 OPD 差 `3.1475e-10 mm`，MTF 最大绝对差 `1.2386e-7`。
- 原处方两组稳定分支发射位置与独立括区间求根参考一致至 `1e-6 mm`；不可解目标与物理口径遮挡分别有回归。
- 教学双胶合与修正版的局部成像各比较 65,536 像素，8 位输出最大差 0；修正版平均能量差 `1.67e-15`。
- 修正版三个视场均通过实际多级采样收敛门槛；不是用几何点列图代替衍射 PSF。

报告：[几何](validation-rayoptics.json)、[波动与成像](validation-diffraction-0.7.json)。独立计算共用导出的入射位置与孔径掩码，不等于对任意多根瞳拓扑的穷尽认证；振幅、标量近似和局部成像范围仍见 [衍射说明](DIFFRACTION.md)。

## 修正版结果

有效焦距 399.997640 mm、F 数 15.999906、近轴后焦距 389.338207 mm，实际像距 388.786311 mm，总长 552.686311 mm。三视场多色 RMS 为 9.231、7.555、14.105 µm；最大半视场 3.095727°。保留原 34 面顺序、教学材料和全部内部间隔，改动曲率、部分后组口径、光阑与像距。

交付文件包含原始和修正两个命名版本。原文件 SHA-256 未变。这是 400 mm f/16 教学实像处方，未复刻佳能 f/2.8，也不认证制造可行性。详见 [修复说明](REPAIR_400MM.md)。

## 实际界面验收

开发浏览器界面连接真实 Rust 0.7 CLI：

- 从“示例与学习”打开修正版，显示 400.00 mm、f/16、正后焦距与三个有限光斑。
- 恢复原始版本后，显示通光未确认、负后焦距与“后方自动对焦不能修复”；自动对焦进一步返回具体曲率/间隔建议。
- 原始模型 64 条失败显示样本被抑制，仅保留 17 条实际光路。失败明细区分 3,298 条瞄准失败与 52 条物理遮挡，全部可查看；点击 S29 后结构树和检查器同步选中 S29。
- 可恢复的 S1 有效直径 1 mm 测试：瞄准失败 0，物理遮挡 3,960；画布开启物理失败显示为 81 条，关闭后为 6 条。随后恢复修正版。
- 实际保存到 JSON，再用文件选择器重开；34 面、原始/修正版两个版本、材料快照和工作区保留。保存文件见 [UI 保存夹具](fixtures/repaired-400mm-ui-saved.oos.json)。
- 全画幅对角视场多色 PSF/MTF 通过 64→128 瞳采样；界面显示 MTF 变化 0.0012、PSF L1 0.0197 与边缘能量 0.23%。
- 重开后生成三个多色分辨率测试图，全部显示收敛已检查、完整 PSF 能量 100%；控制台无错误。实际下载保存的 JSON 与规范修正版逐字段完全相同。

UI 记录：[validation-aiming-ui.json](validation-aiming-ui.json)。证据：[点列图](screenshots/repaired-400mm-0.7.jpg)、[分阶段诊断](screenshots/failure-diagnosis-0.7.jpg)、[衍射收敛](screenshots/psf-mtf-400mm-0.7.jpg)、[重开后成像](screenshots/imaging-400mm-0.7.jpg)。浏览器验证不冒充完整原生桌面人工走查。
