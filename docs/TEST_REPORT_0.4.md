## 实际界面验收

使用本地 Vite 界面和真实 Rust CLI，无模拟计算结果。

1. 打开原有机械环带项目，记录并重命名“机械环带基准”；31 点、17×17 扫描推荐像距 43.333333 mm，扫描指标 62.396 µm。候选 33×33 复核 RMS 390.56 → 62.95 µm，确认原处方仍为 50 mm 像距。
2. 将对焦候选记录为独立版本并重命名。A/B 两边 33×33 重算，点列图共同半宽 1.076041 mm，两侧比例尺均为 566 µm，分别显示 0/7173 失败光线。
3. 保存实际 `.oos.json` 文件，创建临时空白项目，再经真实文件选择器重开；两个版本名称、处方、扫描设置、优化约束均保留；机械直径 26 mm、有效直径 16/12 mm、有效焦距 52.62 mm 与 RMS 385.42 µm 恢复一致。原生文本读写另有 Windows 单元测试。
4. 机械环带仅优化像距：RMS 390.56 → 62.86 µm，9 次迭代，表格逐项显示焦距误差、总长、中心/实体厚度、空气间隔与通光通过。
5. 打开 `examples/version-workflow.oos.json`，比较双胶合对焦基准和像面后移 0.05 mm。PSF 共用 50 µm 视窗与密度峰值；两者瞳采样均 64→128，MTF 收敛变化约 0.0008/0.0007；MTF 共用 0–200 lp/mm 横轴。
6. 将工作区最小中心厚度要求改成 20 mm，只允许像距优化；5 mm、2 mm 两片厚度标记未通过，尽管 RMS 降低，采纳按钮仍禁用。撤销恢复原限制。
7. 当前设计传感器宽度改为 37 mm 后，与保存版本比较提示配置不同并禁用计算；明确勾选临时对齐后可计算，而当前设计仍显示 37 mm。撤销后恢复 36 mm 和已保存状态。
8. 验证聚焦镜组、拖动平移、滚轮缩放（100%→123%→212%）、适应全部与镜片选择联动；镜片和光线同步变换，光学指标不变，保存状态不变。验收发现并修复了 React 延迟更新读取可变拖动坐标的问题。
9. 启动 101 点、33×33 扫描后取消，提示“原设计未改变”，没有候选覆盖原处方。保存的扫描范围仍可恢复。

## 未覆盖与适用边界

- 原生 Windows 文件对话框的完整手动流程、关闭窗口保护的全路径验收，以及无 WebView2 的干净 Windows 虚拟机断网安装尚未执行。浏览器文件选择流程和原生 IO 单元测试不能替代这些验证。
- 未做代码签名；远程 CI 配置已更新，但本次没有触发远程 CI。
- RMS 扫描与优化受声明的几何采样限制；最终 33×33 全通光不是连续孔径处处无损的证明。最薄处数值是采样估计，通过状态由连续区间算法决定，不能解释为制造、公差或强度认证。
- 优化为固定材料的局部 DLS，最多 25 次迭代；可能无法找到可行候选，不承诺全局最优或 RMS 必然降低。
- 处方与版本元数据持久化，计算图像与曲线不作为缓存写入项目；对比重新计算。PSF 图的重采样仅用于共同尺度显示，原始计算和 MTF 不受影响。
- 既有衍射适用性、收敛阈值和局部平面成像范围保持不变。未实现整幅空间变化卷积和畸变映射。
