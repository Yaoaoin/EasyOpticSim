# OpenOpticSim 0.5：独立滚动与复杂镜头导航

窗口顶栏、项目工具栏和底部计算状态保持可见。工作区分为四个滚动区域：左上透镜/镜组列表、左下顺序表面列表、中央光路与分析、右侧参数。滚动一个区域或滚到它的边界，不会带动其他区域。

## 左侧结构

- 透镜和表面始终分开显示，基础/专业模式共用同一结构导航。独立光阑显示在表面列表中，胶合组显示组成片数和表面范围。
- 拖动两个列表之间的横向分隔条可调整比例，范围为 25%–75%。分隔条获得键盘焦点后，可用上下键调整，Home/End 到达上下限。
- 搜索支持名称、材料和面号，例如 `S22`、`胶合` 或 `Teaching flint`。搜索只过滤导航，不改变处方或通光。
- 从列表、画布或几何检查选择表面后，两个列表会分别滚动到选中表面及其所属镜组。定位只滚动各自列表。
- “定位当前选择”会清除过滤并显示当前选中项。如果从别处选择了被当前搜索隐藏的表面，过滤会自动清除。
- 列表获得焦点后，上下键选择相邻项，Home/End 跳到首项或末项。表面列表按顺序面导航；透镜列表按整组导航。
- 添加镜片、添加表面、传感器信息和“示例与学习”入口固定在左侧底部。教学示例和观察任务位于弹窗内。

## 右侧参数

基础/专业切换、当前表面编号和快速导航固定在顶部。参数内容单独滚动；选择另一镜片/镜组或在专业模式选择另一面后，参数回到顶部，避免继续显示先前结构的底部设置。

“镜片 / 面”“摄影”“优化”按钮仅滚动参数区。优化入口在专业模式显示。编辑参数时仍沿用原有单位、验证、撤销和计算流程。

## 工作区布局

项目工具栏的两个侧栏图标可以独立收起左侧结构或右侧参数，为画布和图表腾出空间。收起后的展开按钮一直保留在项目工具栏。

侧栏显示状态和左右列表的比例存储在本机 UI 偏好中，下次打开应用时恢复。“恢复工作区布局”会展开两侧、恢复 45%/55% 比例，并清除结构搜索。

布局、搜索、滚动和选中状态均不作为光学处方参数，也不加入项目版本或撤销记录。它们不会让原本已保存的设计变成未保存状态。项目文件、材料、光学计算和持久化版本格式继续兼容 0.4。

验收覆盖了 12 镜组、27 表面的教学压力算例，以及 1000×720 最小桌面窗口和 1440×940 默认窗口。详见 [验证报告](TEST_REPORT.md) 和 [滚动测量数据](validation-navigation.json)。
